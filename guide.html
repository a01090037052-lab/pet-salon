소개

펫살롱이란?

펫살롱은 애견 미용 샵의 전체 운영을 관리하기 위해 설계된 웹 기반 고객 관리 시스템입니다. 매장에서 필요한 모든 기능을 한 곳에서 사용할 수 있습니다.

주요 특징

📱
완벽한 모바일 지원
스마트폰, 태블릿에서 자유롭게 사용
⚡
초고속
로딩 지연 없이 빠른 반응
📴
오프라인 작동

💾

📸

시작하기

첫 설정 순서

1
매장 정보 입력

설정 > 매장 관리에서 매장 이름, 전화번호, 주소를 입력합니다.

2
미용사 등록

설정 > 매장 관리에서 담당 미용사 이름을 추가합니다.

3
서비스 메뉴 등록

서비스 메뉴에서 미용 서비스(목욕, 드라이, 트리밍 등)와 가격(소형/중형/대형)을 설정합니다.

4
첫 고객 등록

고객 관리에서 보호자 정보와 반려견 정보를 등록합니다.

💡
팁

설정을 먼저 완료해야 예약 및 기록 작성이 정확하게 작동합니다. 특히 서비스 메뉴 가격 설정이 중요합니다.

일일 사용 가이드

아침: 오늘 예약 확인

앱을 열면 대시보드에 오늘의 예약 목록이 표시됩니다. 몇 건의 예약이 있는지, 어떤 고객들이 올 예정인지 한눈에 확인할 수 있습니다.

대시보드 확인 사항
  • 오늘 예약 건수 및 시간
  • 고객명, 반려견명
  • 미용사별 일정
  • 미수금 현황
  • 재방문 알림 (7일 초과)
  • 생일 축하 알림 (7일 이내)

전화 예약: 고객 및 반려견 검색

  1. 전화를 받으면 좌측 상단의 돋보기 아이콘 또는 /를 눌러 검색창을 엽니다.
  2. 고객 이름이나 반려견 이름, 전화번호를 입력하여 검색합니다.
  3. 기존 고객이면 조회 후 "예약" 버튼을 클릭합니다.
  4. 신규 고객이면 검색 결과 하단의 "+ 새 반려견 등록"을 클릭합니다.
  5. 검색어가 반려견 이름에 자동 입력됩니다.

현장 접수: 신규 고객 빠르게 등록

고객이 방문했을 때 빠르게 등록하려면:

  1. 돋보기 검색 또는 하단 + 버튼 → "새 고객"을 선택합니다.
  2. 반려견 이름(필수)을 먼저 입력합니다.
  3. 연락처(필수)를 입력합니다. 이미 등록된 번호면 실시간 안내가 표시됩니다.
  4. 보호자 이름, 견종, 몸무게는 선택 — 나중에 수정 가능합니다.
  5. 저장 후 바로 예약 등록 또는 상세 보기를 선택합니다.

캘린더에서 빠른 예약

예약 페이지의 캘린더에서 원하는 날짜를 탭하면:

  1. 해당 날짜의 예약 요약(시간 + 반려견 이름)이 바로 표시됩니다.
  2. "+ 이 날짜에 예약 추가" 버튼으로 날짜 입력 없이 바로 예약할 수 있습니다.
  3. 좌우 스와이프로 월을 이동할 수 있습니다.

미용 완료: 기록 작성부터 문자 발송까지

1
미용 기록 작성

예약 목록에서 "미용 완료" 버튼을 클릭하거나, 미용 기록 페이지에서 새 기록을 추가합니다. 서비스, 가격, 다음 예약일 등을 입력합니다.

2
사진 카드 (특별한 날만)

더보기 → 사진 카드에서 사진첩 사진을 골라 만듭니다. 레이아웃(네컷·피드·스토리·2컷·폴라로이드)과 테마(클래식·필름·파스텔·다크·커스텀·내 프레임)를 고르면 바로 미리보기가 보입니다. 반려견을 고르면 이름이 들어가고 최근 기록 사진도 가져올 수 있습니다. 카드는 앱에 저장되지 않으며 폰 저장·공유만 합니다.

3
다음 예약 제안

고객에게 다음 미용 추천 날짜를 제시하고 예약합니다.

4
완료 문자 발송

미용 완료 안내 문자를 발송합니다. 미용 기록 옆의 "문자" 버튼으로 한 번에 전송할 수 있습니다.

퇴근: 일일 정산

매출 페이지에서:

  • 오늘 총 매출 확인
  • 결제 수단별 통계 확인
  • 미수금 고객 확인 및 연락
  • 필요시 일일 정산표 다운로드
💡
효율 팁

예약 시간대에 미용 기록 완료 여부를 실시간으로 업데이트하면, 매출 추적과 고객 만족도 향상에 도움이 됩니다.

메뉴별 상세 가이드

대시보드

앱을 열었을 때 가장 먼저 보는 페이지입니다. 당일 주요 정보를 한눈에 파악할 수 있습니다.

주요 기능
  • 아이폰 홈 화면 추가 안내: 사파리 탭으로만 쓰면 7일 미사용 시 iOS가 저장 데이터를 지울 수 있어, 홈 화면에 추가하지 않은 아이폰에는 홈에 안내가 뜹니다 (닫으면 90일 뒤 다시).
  • 오늘 요약 한 줄: 인사말 아래 "오늘 예약 N건 · 주의 반려견 N마리 · 미결제 N건". 주의 반려견은 오늘 예약 중 건강·알러지 특이사항이 있거나 직전 기록이 '주의'/'까다로움'인 아이. 각 항목을 누르면 해당 화면으로 갑니다.
  • 오늘 예약 (상단): 본일 예약 목록 (상태: 대기, 확정, 미용중, 완료, 취소, 노쇼)
  • 오늘 매출 / 이번 달 매출 (상단): 매일 자주 확인 → 상단 배치 (전월 대비 % + 목표 진행률)
  • 미수금 현황: 미지급 건 조회 및 결제 처리
  • 내일 예약 리마인더: 사진+품종/체중, 발송 추적, 노쇼 경고
  • 고객 관리 현황: 이탈 위험·이탈 카운트 (분석 페이지로 빠른 이동)
  • 재방문 알림: 마지막 미용 후 설정 기간이 지난 반려견 (문자/전화 즉시 발송)
  • VIP 미방문 알림: VIP 손님 30일+ 미방문 (전화 즉시 발신)
  • 생일 알림: 7일 내 생일인 고객 및 반려견
  • 백업 알림: 데이터 안전을 위한 백업 권고

예약 관리

고객 예약을 효율적으로 관리하는 페이지입니다.

주요 기능
  • 캘린더 뷰: 월별 캘린더에 예약 바(반려견 이름 + 상태 색상) 표시. 히트맵 배경으로 바쁜 날 한눈에 파악. 좌우 스와이프로 월 이동.
  • 날짜 요약 패널: 캘린더 날짜 탭 → 해당 날짜 예약 목록 + "예약 추가" 버튼 바로 노출
  • 토/일 색상 구분: 토요일(파랑), 일요일(빨강)으로 주말 즉시 구분
  • 오늘 강조: 원형 파란 배경 + "오늘" 버튼으로 빠른 복귀
  • 타임테이블: 미용사별 일정을 시간 단위로 관리 (8~22시)
  • 반복 예약: 주 1회, 2주, 4주 등 정기 예약 생성
  • 예약 상태 변경: 대기 → 확정 → 미용중 → 완료
  • 시간 충돌 감지: 미용사별, 반려견별 중복 예약 방지

미용 기록

완료된 미용 작업을 기록하고 관리합니다.

주요 기능
  • 기록 작성: 서비스, 스타일, 추가항목, 금액, 담당 미용사, 컨디션 기입
  • 미용 협조도: 잘함/보통/까다로움 — 다음 미용 시간 견적 참고
  • 이전 미용과 같음: 단골 손님은 1탭으로 자동 채움 (서비스·추가항목·가격·스타일·미용사). 컨디션·협조도·결제수단은 매번 다르므로 채움 안 함
  • 미용사 자동 채움: 1인 매장(등록 미용사 1명)이면 자동 입력
  • 날짜 그룹핑: 오늘/어제/이번 주/월별 자동 섹션 구분
  • 필터 합계 바: 검색/필터 결과의 건수·합계·미결제 소계 실시간 표시
  • 기록 사진 (전·후 2장): 다음 미용 때 "지난번엔 어떻게 했지?"를 확인하는 용도. 반려견별 최근 3회 기록의 사진만 보관하고 더 오래된 기록의 사진은 자동 정리됩니다 (설정 → 데이터 → 기록 사진 보관에서 2회·3회·5회·전부 선택). 반려견 상세 맨 위 "최근 미용 사진" 줄에서 한눈에 보고(전·후가 둘 다 있으면 타일 아래 "전 | 후"로 번갈아 봄), 동기화를 켜면 다른 기기에서도 보입니다 (600px 축소본).
  • 미용 리포트 (보호자 전송용): 기록 저장 완료 창의 "리포트 보내기", 기록 목록·고객 상세 최근 기록의 리포트 버튼. 전·후 사진 + 오늘 한 것 + 오늘 상태(컨디션·협조·피부·귀·엉킴을 색 점으로) + 미용사 한마디(메모) + 집에서 관리법 + 다음 미용 추천일 + 매장명을 이미지 한 장으로 만들어 카톡·문자로 보냅니다. 빈 항목은 자동으로 빠지고, 리포트는 앱에 저장되지 않습니다. 설정 → 매장 관리에 리뷰 링크를 넣으면 하단에 "리뷰 남겨주시면 큰 힘이 돼요"가 붙습니다.
  • 사진 카드: 기록과 별개로 더보기 → 사진 카드에서 만듭니다. 아래 "사진 카드 기능" 참고.
  • 영수증 생성: 서비스 포함 항목까지 자동 노출 (└ 발톱·귀청소·항문샘 등)
  • 결제 상태: 카드, 현금, 이체, 미결제 (칩 선택)
  • 다음 예약일: 미용 주기 자동 계산 + 저장 후 바로 예약
  • 삭제 안전성: 삭제 확인 시 날짜·반려견·금액 표시 (실수 방지)
  • 일일 정산표: 결제 수단별·미용사별 집계 + 시간순 상세 내역

고객 관리

고객 정보를 체계적으로 관리합니다.

주요 기능
  • 고객 목록: 이름순, 최근방문순, 등록일순, 방문횟수순 정렬
  • 고객 분류: VIP, 신규, 단골, 주의 태그 설정
  • 고객 상세: 방문 통계, 미용 기록, 반려견 목록 조회
  • 미수금 확인: 고객별 미지급액 추적
  • 전화/문자: 직접 연락 기능
  • 메모: 고객 특이사항 기록

반려견 관리

반려견의 개별 정보와 관리 정보를 기록합니다.

주요 기능
  • 반려견 프로필: 이름, 견종, 체중, 나이, 성별, 중성화 여부
  • 건강 정보: 성격, 건강 특이사항, 알러지, 선호 스타일
  • 사진: 반려견 프로필 사진 업로드
  • 미용 주기: 개별 반려견별 권장 미용 주기 설정
  • 상태 관리: 활동중, 사망, 양도 등 상태 기록
  • 응대 카드 (상세): 단골 응대 시 한눈에 — 다음 미용일(D-N), 최근 방문, 최근 컨디션, 미용 협조도 + 5회 추이
  • 알러지/건강 경고: 알러지나 건강 특이사항 있으면 상단 빨강 배너
  • 다음 미용일 자동 예측: 권장 주기 미설정 시 실제 평균 방문 주기로 자동 계산
  • 목록 카드 디자인: 좌측 4px 컬러바(이탈/리마인드/정상/이탈) + 사진 60px + 우측 상태 칩
  • 그룹 헤더: 정렬 '상태별' 선택 시 자동 분리 (이탈 임박 N마리 / 리마인드 N마리 / ...)
  • 미용 이력: 해당 반려견의 모든 미용 기록 조회 + 컨디션·협조도 색상 점

매출 분석

수익성을 분석하고 전략을 수립합니다.

매출 페이지
  • 오늘 매출: 본일 매출 목표 진행률
  • 이번 주/달 매출: 기간별 수익 요약
  • 일별/월별 차트: 시각적 매출 추이 분석 (모바일 가독성 강화 + 주별 합계 라인)
  • 결제 수단별 통계: 현금, 카드, 이체 분석
  • 미용사별 매출: 담당자별 성과 파악
  • 손익 계산: 고정비, 변동비 입력 후 순이익 계산
  • CSV 내보내기: 세무사 제출용 자료 추출

사진 카드 기능

특별한 날(첫 미용·생일·시즌 이벤트) 사진첩 사진으로 공유용 카드를 만듭니다. 미용 기록과는 별개 기능이며, 만든 카드는 앱에 저장되지 않고 폰에 저장하거나 공유만 합니다 (저장 용량을 쓰지 않음).

카드 만들기

  1. 더보기 → 사진 카드를 엽니다 (데스크탑은 왼쪽 메뉴).
  2. 반려견을 고릅니다 (선택). 고르면 이름이 카드에 들어가고 보호자 번호로 문자 열기가 가능하며, 만들기 창에서 "○○ 기록 사진 넣기"로 최근 미용 기록 사진을 가져올 수 있습니다.
  3. 날짜를 확인하고 "사진 골라서 카드 만들기"를 누릅니다.
  4. 사진 칸(4칸)을 눌러 사진첩에서 먼저 고릅니다 (1~4장). 고른 장수에 맞는 레이아웃에 "추천" 표시가 붙습니다.
  5. 레이아웃을 고릅니다: 네컷 세로 · 피드(4:5) · 스토리(9:16) · 피드 4컷 · 스토리 4컷 · 2컷 · 폴라로이드(1:1). 피드 4컷·스토리 4컷은 사진 4장을 칸마다 띄운 2×2 격자로 크게 보여 주며, 4장을 고르면 '추천'이 붙습니다. 고르는 즉시 위에 미리보기가 바뀌고, 레이아웃을 바꿔도 고른 사진은 그대로입니다. 피드·스토리는 고른 장수대로 자동 분할됩니다: 2장은 나란히, 3장은 위 1칸 + 아래 2칸, 4장은 2×2. 네컷은 칸보다 적게 고르면 칸 수가 줄어들어 크게 나옵니다. 칸마다 위치·확대를 조절할 수 있습니다.
  6. 테마를 고릅니다: 클래식 · 필름 · 파스텔 · 다크 · 커스텀 · 내 프레임.
  7. 스티커를 붙입니다: 스티커 줄(가로로 밀기)에서 누르면 미리보기 가운데에 붙습니다. 미리보기에서 손가락으로 끌어 옮기고, 아래 슬라이더로 크기·회전을 맞추고, "이 스티커 삭제"·"모두 지우기"로 지웁니다. 스티커를 고른 동안은 미리보기가 커집니다. 스티커는 사진·프레임보다 위에 찍히고, "다시 꾸미기"로 돌아와도 그대로 남아 있습니다. 스티커 줄 위의 묶음 버튼으로 세련된(차분한 색 배지·라벨·오라 22개: GOOD VIBES·NO BAD HAIR DAYS·FRESH CUT·PUPPY CLUB·오늘 미용 완료 등) · 이모지(Google Noto Emoji, Apache 2.0)를 바꿔 봅니다.
  8. 글자 스티커: 스티커 줄 맨 앞 "가 글자" → 문구 입력 → 모양(말풍선·분홍 라벨·검정 라벨·글자만) → 붙이기. 고른 사진 카드 글꼴로 그려지고, 붙인 뒤에도 눌러서 글자·모양을 고칠 수 있습니다.
  9. 내 스티커: "+ 내 스티커"로 사진첩 그림을 올립니다(여러 장 가능, 최대 24개). ChatGPT 등으로 만든 그림의 흰색·단색 배경은 자동으로 지우고 빈 여백을 잘라 냅니다. "내 스티커 정리"를 누른 뒤 지울 스티커를 누르면 목록에서 빠집니다. 내 스티커는 이 기기에만 보관됩니다(동기화 안 함, 백업 파일에는 포함).
  10. 글꼴을 고릅니다: 기본 · 고운돋움 · 주아 · 도현 · 개구 손글씨 · 나눔펜 · 고운바탕 · 페이퍼로지 (모두 무료 글꼴). 처음 고를 때 인터넷으로 한 번 받고, 그 뒤에는 오프라인에서도 쓸 수 있습니다. 받지 못하면 기본 글꼴로 나옵니다.
  11. 카드에 넣을 글자에서 반려견 이름 · 날짜 · 매장명(로고)을 각각 켜고 끕니다. 모두 끄면 사진만 남은 깔끔한 카드가 됩니다. "더 꾸미기"에서 문구·서비스명·다음 방문일·로고 위치를 바꿉니다.
  12. 창은 위에 작은 미리보기, 아래에 탭 5개(사진 · 틀 · 꾸미기 · 스티커 · 글자)로 나뉩니다. 사진 탭은 작은 칸 4개 한 줄 — 칸을 눌러 고르고, ×로 빼고, "위치"로 위치·확대를 맞춥니다. 틀=레이아웃, 꾸미기=테마·내 프레임·색·배경·글꼴, 글자=이름·날짜·매장명 표시와 문구·로고 위치. 컴퓨터에서는 왼쪽에 큰 미리보기, 오른쪽에 탭이 나옵니다.
  13. "완성하기" → 완성 화면에서 공유하기(카톡·문자·인스타) / 저장 / 인쇄용 4×6 / 인스타 피드·스토리용 저장 / 보호자 번호로 문자 열기 / 다시 꾸미기.

  • 하단 15~20%: 헤드라인·서브·푸터·다음방문일 자동 → 비워두기
  • 가장자리 50px: 안전 여백 (잘림 방지)

배경 이미지에는 텍스트 ❌ — 텍스트는 앱 안에서 자유 입력 (자동 위치)

파일 설정

  • 색상 모드: sRGB (웹 표준)
  • 해상도: 72dpi (웹용)
  • 파일 형식: JPG 권장 (가벼움) — 투명 배경 필요 시 PNG
  • 파일 크기: 1MB 이하 권장 (앱 로딩 빠름)
  • JPG 압축률: 85%

피그마 작업 순서

  1. Frame 생성: File → Design → Frame → 위 표 크기 입력
  2. 안전 영역 가이드 라인: 빨강 외곽선 사각형 + 잠금 (참고용)
  3. 배경 디자인: 단색·그라데이션·옅은 패턴 (중앙은 옅게)
  4. Export: Selection → Export → JPG 1x, Quality 85
  5. 앱 업로드: 더보기 → 설정 → 내 프레임에 등록하면 사진 카드의 테마 줄에 바로 나옵니다 (또는 만들기 창 → 커스텀 → 배경 이미지)

매장 브랜딩 4단계 권장

  1. 시그니처 컬러: 매장 간판·로고에서 1~2색 선정 → 포인트 색으로 사용
  2. 배경 톤: 사진이 잘 보이는 밝은 톤 (사진 컬러를 죽이지 않음)
  3. 로고 위치: 상단=브랜딩 강조 / 하단=사진 강조 / 중앙 워터마크=재공유 방지
  4. 5종 동일 컨셉 세트: 같은 배경색·패턴, 비율만 다르게 → 인스타 통일감

흔한 실수 5가지

  • ❌ 배경에 큰 텍스트 → ✅ 텍스트는 앱 자유 텍스트로 입력
  • ❌ 사진 영역에 진한 무늬 → ✅ 중앙은 옅게
  • ❌ 가장자리에 중요 정보 → ✅ 50px 안전 여백 확보
  • ❌ PNG 큰 파일 (10MB+) → ✅ JPG 1MB 이하
  • ❌ 다른 비율 사용 (예: 1920×1080) → ✅ 정확한 비율 (1080×1350 등)

제작 체크리스트

  • ☑ 비율 정확 (4:5 / 9:16 / 1:1 등)
  • ☑ 1080px 너비 이상
  • ☑ JPG 1MB 이하
  • ☑ 중앙 사진 영역 옅음
  • ☑ 가장자리 50px 안전 여백
  • ☑ 상단/하단 텍스트 영역 비어있음
  • ☑ 매장 컬러 톤 반영

💡 배경 이미지 디자인 권장 패턴

1. "프레임만 디자인" 패턴 (가장 단순)

  • 전체를 배경색·패턴으로 채움 (단색·옅은 그라데이션·미세 무늬)

  • 가장자리에만 장식 (선·코너 일러스트)
  • 예: 베이지 배경 + 가장자리 미세한 꽃 일러스트

2. "윈도우 프레임" 패턴 (사진 영역 강조)

  • 사진 영역 주변에 흰색 테두리 (폴라로이드 시그니처)
  • 그 외 배경은 매장 시그니처 컬러
  • 예: 네이비 배경 + 흰색 사진 프레임 + 골드 포인트

3. "일러스트 코너" 패턴 (감성 강조)

  • 네 모서리에만 일러스트 (꽃·별·하트 등)
  • 중앙·텍스트 영역은 완전 비움
  • 시즌별 일러스트만 교체 → 매장 정체성 유지
  • 예: 매장 시그니처 컬러 + 봄=벚꽃, 여름=조개, 가을=낙엽, 겨울=눈

4. "투명 배경" 패턴 (배경 X)

  • 커스텀 테마의 배경색만 활용
  • 배경 이미지 X (가장 가벼움)
  • 매장 시그니처 컬러 + 글자색만으로 깔끔
  • 저장 공간 0MB

내 프레임 라이브러리 사용법

시즌·이벤트별 프레임을 미리 만들어 두면 사진 카드 생성 시 1탭으로 선택할 수 있습니다. 최대 5개 슬롯.

진입 경로

  1. 설정 → 매장 관리 탭
  2. "🖼 내 프레임 라이브러리" 카드
  3. "+ 새 프레임 추가" 버튼

새 프레임 추가 단계

  1. 이름 입력: "봄 시즌 2026", "크리스마스", "여름 시즌" 등 알아보기 쉬운 이름
  2. 이미지: 피그마·캔바로 만든 PNG/JPG 업로드
  3. 방식: 배경(사진 뒤에 깔기, 예전 방식) 또는 덮기(사진 위에 얹기 — 인생네컷처럼 사진 칸을 투명하게 뚫은 PNG). 덮기를 고르면 "칸 위치 가이드 저장"으로 레이아웃별 가이드 이미지(사진 칸에 1~4 번호)를 받을 수 있습니다. 가이드를 캔바에 깔고 디자인한 뒤, 번호 칸을 투명하게 지워 PNG로 저장해 올리면 칸이 정확히 맞습니다. 가이드는 지금 사진 카드 설정(이름·날짜 표시 등) 그대로 만들어지니, 카드에 쓸 설정을 먼저 맞춰 두세요.
  4. 포인트 색: 헤드라인·강조 텍스트 색 (매장 시그니처 또는 시즌 컬러)
  5. 글자 색: 본문 텍스트 색 (배경과 대비 강하게)
  6. 활성/비활성: 사진 카드 생성 시 노출 여부
  7. 저장

사진 카드에서 사용하기

  1. 미용 기록 → 카드 아이콘 (📷) 클릭
  2. "테마" 영역에서 등록한 프레임 클릭 (썸네일과 이름 표시)
  3. 나머지 옵션 (사진·자유 텍스트 등) 설정
  4. "완성하기" → 미리보기 확인 → 공유/저장

한 번 선택한 프레임은 다음 카드 만들 때 자동으로 선택되어 있어요 (마지막 사용 기억).

프레임 관리

  • 편집: 라이브러리에서 프레임 카드 어디든 탭 → 편집 모달
  • 삭제: 우측 🗑 버튼
  • 활성/비활성: 카드 안 토글 (편집 모달 안 거치고 즉시)

매장 브랜딩 일관성 팁

시즌마다 컨셉을 완전히 바꾸지 마시고, 매장 시그니처 컬러는 고정한 채 시즌 보조 색만 변경하세요.

  • 매장 시그니처 컬러: 베이지 + 검정 (고정)
  • 봄: 베이지 + 검정 + 핑크 포인트
  • 여름: 베이지 + 검정 + 민트 포인트
  • 겨울: 베이지 + 검정 + 골드 포인트

→ 손님이 매장 시그니처를 즉시 인지하면서도 시즌감 전달.

  • 5개 슬롯 합산 약 5MB 이하 유지
  • 10MB 이상 시 앱 로딩·백업 부담
  • 피그마 Export 시 JPG 85% 압축으로 저장 권장

인스타그램 최적화

  • 모든 레이아웃은 1080px 이상으로 자동 업스케일 (흐림 방지)
  • 피드: 1080×1350 (4:5) → 피드에서 최대 면적 차지
  • 스토리: 1080×1920 (9:16) → 스토리 전체 화면
  • 생성 후 "공유하기" → 인스타/카톡/에어드롭으로 바로 전송

스티커 만들기 가이드

사진 카드의 스티커 탭에서 쓰는 스티커는 네 가지입니다: ① 앱에 들어 있는 기본 스티커 ② 글자 스티커 ③ 내 로고 스티커 ④ 직접 만들어 올린 내 스티커.

1. 기본 스티커 쓰기

  1. 사진 카드 → 사진을 고른 뒤 스티커 탭.
  2. 위의 묶음 버튼(세련된·이모지 등)으로 분위기를 고르고, 스티커를 누르면 미리보기 가운데에 붙습니다.
  3. 미리보기에서 손가락으로 끌어 옮기고, 아래 크기·회전 슬라이더로 맞춥니다. 지우려면 "이 스티커 삭제".
  4. 한 카드에 2~4개가 가장 보기 좋습니다. 얼굴·눈 위는 피하고 모서리 쪽에 두세요.

2. 글자 스티커

"가 글자" → 문구 입력(24자까지) → 모양(말풍선·분홍 라벨·검정 라벨·글자만) → 붙이기. 꾸미기 탭에서 고른 글꼴로 그려지고, 붙인 뒤 눌러서 글자·모양을 고칠 수 있습니다. 한글 문구는 글자 스티커로 넣는 것이 가장 깔끔합니다.

3. 내 로고 스티커

  1. 먼저 설정 → 매장 정보 → 매장 로고에 로고를 올립니다. 배경이 투명한 PNG가 가장 좋습니다.
  2. 사진 카드 → 스티커 탭 → "◎ 내 로고" → 모양을 고릅니다.
    • 그대로: 로고 모양 둘레에 흰 테두리를 둘러 스티커처럼
    • 원형 배지: 테마 색 원 안에 로고, 둘레에 매장명 · GROOMING 글자
    • 라벨: 크림색 라벨에 로고 + 매장명
  3. 로고를 바꾸면 다음부터 새 로고로 만들어집니다.

4. 내 스티커 직접 만들어 올리기

스티커 탭 맨 앞 "+ 내 스티커"로 사진첩의 그림을 올립니다(여러 장 한 번에, 최대 24개). 흰색·단색 배경은 앱이 자동으로 지우고 빈 여백을 잘라 냅니다. 내 스티커는 이 기기에만 보관됩니다(백업 파일에는 포함).

    애견 미용실 사진 카드에 붙일 스티커를 만들어줘. 한 이미지에 스티커 1개, 가운데 배치, 둘레에 굵은 흰색 다이컷 테두리, 배경은 진짜 투명 PNG(체크무늬 금지). 스타일: [레트로 과일 라벨 / 검정·흰·코발트 미니멀 / 버건디·크림 브랜드 손글씨 / 파스텔 귀여운]. 글자는 영어로 정확히: '[문구]'. 주제: [예: 웃는 푸들 얼굴].
  2. 마음에 드는 그림을 사진첩에 저장 → 앱에서 "+ 내 스티커"로 올립니다.

캔바·미리캔버스로 만들기

  1. 정사각 캔버스(예: 1000×1000)에 요소·글자를 배치합니다.
  2. 배경을 흰색 한 가지로 두고 PNG로 저장합니다(투명 배경 저장이 유료여도 괜찮습니다 — 앱이 흰 배경을 지웁니다).
  3. 스티커 그림 바깥쪽이 흰 배경과 닿아 있어야 깔끔하게 지워집니다. 그림 안의 흰색은 남습니다.

잘 만드는 요령

  • 색은 2~3가지만. 매장 테마 색 하나를 꼭 넣으면 카드와 잘 어울립니다.
  • 글자는 짧게(영어 2~3단어, 한글은 글자 스티커로). AI 그림은 한글 글자가 자주 틀립니다.
  • 그림은 가로·세로 400px 이상으로. 작으면 카드에서 흐려 보입니다.
  • 체크무늬 배경은 "가짜 투명"이라 지워지지 않습니다. ChatGPT에 "진짜 투명 배경 PNG로 다시"라고 요청하세요.

주의 (저작권)

  • 다른 회사 로고·캐릭터(디즈니·산리오 등)나 남의 그림을 그대로 쓰면 안 됩니다. 직접 만들었거나 상업용 무료로 받은 것만 쓰세요.
  • ChatGPT·캔바로 만든 그림은 각 서비스 약관상 내 홍보물에 쓸 수 있는 경우가 대부분이지만, 무료 요소마다 조건이 다를 수 있어 캔바는 요소의 "상업적 이용 가능" 표시를 확인하세요.

데이터 관리

백업 방법

두 가지 백업 옵션이 있습니다:

  • 백업 (사진 제외 · 권장): 고객·예약·기록 데이터만 저장. 빠르고 가벼움 (수 MB).
  • 사진 포함 백업: 사진 데이터까지 포함. 용량이 크므로 주의 (수백 MB 가능).
  1. 설정 > 데이터 탭으로 이동합니다.
  2. "백업 (사진 제외 · 권장)" 또는 "사진 포함 백업" 버튼을 클릭합니다.
  3. JSON 파일이 다운로드됩니다. 파일 이름에 날짜+시간이 포함됩니다.
  4. 카톡 나에게 보내기나 클라우드에 보관하면 폰 분실 시에도 안전합니다.
💡 iOS 사용자 주의: iPhone Safari에서는 7일 이상 앱을 사용하지 않으면 데이터가 삭제될 수 있습니다. 홈 화면에 앱을 추가하고, 정기적으로 백업해주세요.
💡
백업 권장사항

최소 1주일에 1번, 데이터가 많을수록 자주 백업하세요. 안전한 클라우드 저장소(Google Drive, iCloud 등)에 복사본을 보관하는 것을 권장합니다.

복원 방법

  1. 설정 > 데이터 탭으로 이동합니다.
  2. "데이터 복원하기" 버튼을 클릭합니다.
  3. 백업 파일(JSON)을 선택합니다.
  4. 확인 메시지를 읽고 진행합니다. (기존 데이터는 덮어쓰기됩니다)
  5. 복원 완료 후 자동으로 이전 데이터를 안전하게 보관합니다.

폰 교체 시 데이터 이전

  1. 기존 폰에서: 설정 > 데이터에서 백업 파일 다운로드
  2. 안전 보관: 백업 파일을 이메일로 전송하거나 USB에 저장
  3. 새 폰에서: 펫살롱 앱 설치 후 복원 기능 사용
  4. 확인: 데이터가 정확히 이전되었는지 확인

백업 파일 보관 중요성

  • 장기 사업 자료 보관: 최소 3년~5년 보관 권장
  • 세무사 상담 시 활용
  • 분쟁 발생 시 증거 자료
  • 새 직원 교육 자료
중요

백업 파일은 매우 중요합니다. 여러 곳에 복사본을 저장하고, 안전한 장소에 보관하세요. 기기 고장이나 분실 시에만 필요하지만, 필요할 때 없으면 모든 데이터를 잃을 수 있습니다.

오프라인 사용법

펫살롱은 오프라인에서도 작동합니다

펫살롱은 PWA(Progressive Web App)로 만들어져서, 한 번 접속하면 인터넷 없이도 사용할 수 있습니다.

오프라인 동작 원리
  • 앱 파일: 처음 접속 시 모든 파일이 기기에 자동 저장(캐시)됩니다
  • 고객 데이터: 모든 데이터는 기기 내부(IndexedDB)에 저장됩니다. 서버로 전송되지 않습니다
  • 인터넷 불필요: 고객 등록, 예약, 미용 기록, 매출 확인 등 모든 기능이 오프라인에서 동작합니다

홈 화면에 앱 설치하기 (추천)

홈 화면에 설치하면 일반 앱처럼 사용할 수 있고, 오프라인 안정성도 높아집니다.

  4. "추가" 탭 → 홈 화면에 펫살롱 아이콘 생성

문제 해결 (FAQ)

Q. 앱이 안 열려요

앱을 여러 번 사용했는데 갑자기 안 열리는 경우가 있습니다. 다음을 시도해보세요: 1) 브라우저 새로고침 (F5 또는 Ctrl+R), 2) 브라우저 캐시 삭제 후 다시 접속, 3) 다른 브라우저 사용, 4) 디바이스 재시작

Q. 데이터가 사라졌어요

먼저 당황하지 마세요! 펫살롱은 기기에 데이터를 저장하므로 웹사이트를 방문하는 방식에 따라 달라질 수 있습니다. 1) 북마크된 정확한 주소로 접속했는지 확인, 2) 홈 화면에 추가했으면 그 아이콘으로 시작, 3) 백업 파일이 있으면 복원 기능으로 데이터 복구

Q. 오프라인에서 사용하려면?

펫살롱은 완벽한 오프라인 지원을 제공합니다. 1) 한 번 접속하면 필요한 파일이 자동 다운로드되고, 2) 이후 인터넷 없이도 모든 기능 사용 가능, 3) 연결 복구 후 자동 동기화. 인터넷 없는 상황에서도 걱정 없이 사용하세요.

Q. 문자가 안 보내져요

1) 고객 연락처가 정확히 입력되었는지 확인, 2) 휴대폰의 SMS 권한이 허용되었는지 확인, 3) 앱 개발자의 SMS 기능은 문자 작성만 자동화하며, 실제 발송은 기기의 기본 문자 앱을 거치므로 발송 여부는 기기에 따라 다를 수 있음

Q. 예약이 겹친다고 나와요

펫살롱은 같은 미용사나 같은 반려견의 예약 시간이 겹치는 것을 방지합니다. 1) 예약 소요시간 재확인, 2) 다른 미용사 배정 또는 시간 변경, 3) 기존 예약 상태 변경 확인

Q. 저장 공간이 부족하다고 해요

사진이 많으면 저장 공간을 많이 사용합니다. 1) 오래된 사진 삭제, 2) 백업 파일 다운로드 후 기기에서 삭제, 3) 별도 클라우드 저장소 활용 고려

Q. 모바일과 PC에서 동시에 쓸 수 있나요?

각 기기는 독립적인 데이터를 가집니다. 데이터를 동기화하려면: 1) 한 기기에서 백업 파일 생성, 2) 다른 기기에서 복원 기능으로 불러오기. 이 방법으로 여러 기기에서 같은 데이터를 사용할 수 있습니다.

Q. 비용이 드나요?

펫살롱은 완전 무료입니다. 광고도 없고, 추가 구독료도 없습니다. 다만 매장의 인터넷 요금은 발생합니다(초기 설정 시에만 필요).

현재 상황 이해

펫살롱은 GitHub Pages라는 무료 호스팅으로 운영되고 있습니다. 이는 개발자가 관리하지 못하는 상황이 생길 수 있음을 의미합니다. 다음은 대비책입니다.

1단계: 정기 백업

  • 최소 주 1회 백업 수행 (설정 > 데이터 > 데이터 백업하기)
  • 여러 곳에 복사본 보관: 외장하드, 클라우드, 이메일
  • 중요 데이터(고객 목록, 재방문 주기)는 엑셀로도 별도 관리 고려

2단계: 다른 호스팅 이용

개발자가 미지우면 다른 호스팅 서비스로 옮길 수 있습니다:

  • Vercel, Netlify 등 무료 호스팅 서비스 이용 가능
  • 자신의 서버/웹호스팅에 설치 가능
  • IT 기술자의 도움 필요 (완전히 자동화되지 않음)

3단계: 다른 개발자에게 인수

기술 능력이 없다면:

  • 개발자 커뮤니티에 요청
  • 백업 파일 제공으로 새로운 버전 개발 요청
  • 유사한 기능의 다른 솔루션 찾기

4단계: 다른 시스템으로 데이터 이전

만약 완전히 다른 시스템으로 옮겨야 한다면:

  1. 펫살롱에서 백업 파일 다운로드
  2. 고객 목록, 반려견 정보, 예약, 기록을 CSV 또는 엑셀로 변환
  3. 새로운 CRM 시스템 또는 미용 관리 소프트웨어로 가져오기

  • IT 전문가에게 기기의 IndexedDB 데이터 복구 문의 가능
  • 이를 위해서도 정기 백업이 최고의 방법입니다

엑셀/노션 연동 가이드

CSV 파일을 엑셀에서 열기

펫살롱에서 내보낸 CSV 파일을 엑셀에서 바로 활용할 수 있습니다.

  1. CSV 다운로드: 매출 페이지 또는 미용 기록 > 세무 자료 내보내기 > 기간 선택 > CSV 다운로드
  2. 엑셀에서 열기: 다운로드된 CSV 파일을 더블클릭하면 엑셀에서 자동으로 열립니다
  3. 한글 깨짐 시: 엑셀 > 데이터 > 텍스트/CSV 가져오기 > 파일 선택 > 인코딩 "UTF-8" 확인 후 가져오기

엑셀에서 매출 분석하기

CSV를 열면 다음 열이 포함됩니다:

날짜, 고객명, 반려견, 견종, 서비스, 기본금액, 할인, 추가요금, 최종금액, 결제수단, 담당 미용사, 메모

피벗 테이블로 분석 (엑셀)

  1. 데이터 영역 선택 후 삽입 > 피벗 테이블
  2. 견종별 매출: 행에 "견종", 값에 "최종금액"(합계)
  3. 월별 매출: 행에 "날짜"(월 그룹화), 값에 "최종금액"(합계)
  4. 미용사별 실적: 행에 "담당 미용사", 값에 "최종금액"(합계) + "최종금액"(개수)
  5. 서비스 인기도: 행에 "서비스", 값에 "최종금액"(개수)

구글 스프레드시트 사용 시

구글 드라이브에 CSV를 업로드하면 구글 스프레드시트에서 바로 열 수 있습니다. 피벗 테이블도 동일하게 사용 가능합니다.

노션(Notion)에서 활용하기

노션에 매출 데이터를 가져와서 데이터베이스로 관리할 수 있습니다.

CSV를 노션으로 가져오기

  1. 노션에서 새 페이지 생성
  2. /table 입력 > "Table - Full page" 선택
  3. 우측 상단 ... 메뉴 > Merge with CSV (CSV 병합)
  4. 다운로드한 CSV 파일 선택
  5. 데이터가 테이블로 자동 생성됩니다

노션 데이터베이스 활용 팁

  • 필터: 견종별, 결제수단별, 미용사별로 필터링
  • 정렬: 날짜순, 금액순 정렬
  • 뷰 전환: 테이블, 보드, 캘린더, 갤러리 등 다양한 뷰 활용
  • 수식: 노션 수식으로 월별 합계, 평균 단가 계산 가능

추천 워크플로우

  1. 매월 1일에 지난달 CSV 내보내기
  2. 노션 "매출 기록" 데이터베이스에 CSV 가져오기
  3. 노션에서 월별 요약 페이지 작성
💡
노션 무료 플랜 주의

노션 무료 플랜에서도 CSV 가져오기와 데이터베이스 기능을 사용할 수 있습니다. 다만 파일 업로드 용량에 제한이 있으니, 너무 오래된 데이터는 분기별로 나눠서 관리하세요.
