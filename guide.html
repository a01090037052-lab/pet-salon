펫살롱은 휴대폰·컴퓨터 브라우저에서 쓰는 무료 고객 관리 앱입니다. 데이터는 기본으로 이 기기 안에 저장되고, 인터넷이 없어도 동작합니다. 아래 1~2장만 읽어도 바로 쓸 수 있고, 나머지는 필요할 때 찾아보세요.

1. 처음 10분 설정

1
매장 정보

더보기 → 설정 → 매장 관리 탭에서 매장 이름·전화번호·주소를 넣습니다. 로고와 리뷰 링크(네이버 플레이스·카카오맵)를 넣으면 리포트·사진 카드·문자에 자동으로 들어갑니다. 쉬는 요일은 휴무일에 지정하세요. 직원이 있을 때만 미용사 관리에 이름을 추가합니다 (혼자면 건너뛰세요).

2
가격 구간 · 서비스 메뉴

설정 → 운영 설정 → 가격 구간 카드의 [구간 편집]에서 몸무게 구간(기본 ~3 / 3~5 / 5~7 / 7~10 / 10kg~)을 확인합니다. 몸무게와 상관없이 같은 가격을 받으면 맨 위 "몸무게 구간 사용 안 함"을 체크하세요.

다음으로 더보기 → 서비스 메뉴에서 [+ 새 서비스]로 만듭니다 (메뉴가 비어 있을 때는 [기본 서비스 등록]으로 기본 메뉴를 골라 넣을 수 있음). 구간 가격은 접힌 "한 번에 채우기"를 열어 첫 구간 가격을 넣고 [채우기]를 누르면 빠릅니다. → 가격 구간 자세히

소·중·대 3단계, 견종별 가격, 목욕 전문, 고양이 등 매장 유형별 설정은 샵 유형별 설정 요령을 보세요.

3
홈 화면에 추가

아이폰(Safari): 아래 공유 버튼(네모+화살표) → "홈 화면에 추가" → "추가".
안드로이드(Chrome): 주소창 아래 "홈 화면에 추가" 배너, 또는 오른쪽 위 ⋮ → 홈 화면에 추가 → "설치".

아이폰은 사파리 탭으로만 쓰다가 7일 넘게 안 열면 저장 데이터가 지워질 수 있어서 꼭 해 두세요.

4
동기화 켜기 또는 백업

휴대폰과 컴퓨터를 같이 쓰면 설정 → 데이터 → 기기 간 동기화에서 [구글로 동기화 켜기] (방법). 한 기기만 쓰면 같은 탭의 [백업 (사진 제외 · 권장)]을 주 1회 누르고, 파일을 카톡 나에게 보내기·클라우드에 보관하세요.

2. 하루 흐름

휴대폰 하단 메뉴: 홈 · 예약 · [+] · 고객 · 더보기. 가운데 [+]로 "새 예약" · "새 미용기록" · "새 고객 · 반려견"을 바로 만듭니다. 컴퓨터는 왼쪽 메뉴를 씁니다.

아침: 홈 확인

홈 맨 위 한 줄 "오늘 예약 N건 · 주의 N마리"를 누르면 예약 화면으로 갑니다. 주의 반려견은 오늘 예약 중 건강·알러지 특이사항이 있거나 직전 기록이 '주의'/'까다로움'인 아이입니다. 아래로 오늘 예약 → 다음 영업일 예약 리마인더 → 미결제 현황 → 연락할 손님 → 매출 → 생일 알림 순서로 나옵니다 (미결제·연락할 손님이 없으면 그 카드는 안 보임).

최근 14일 예약 중 아직 대기·확정·미용중인 건이 있으면 맨 위에 "마감 안 한 지난 예약 N건" 줄이 뜹니다. 누르면 예약 화면이 그 건들만 보여 주고, [기본 보기로]로 돌아옵니다. 하나씩 완료·취소·노쇼로 정리하세요.

예약 받기

  1. 전화가 오면 손님을 찾습니다. 휴대폰은 화면 오른쪽 위 돋보기, 컴퓨터는 왼쪽 메뉴의 찾기나 / 키(또는 Ctrl+K). 이름·반려견 이름·전화번호 뒷자리 4개("9876")·초성("ㅊㅋ" → 초코) 모두 됩니다.
  2. 기존 손님이면 결과에서 예약을 누릅니다.
  3. 새 손님이면 고객 탭의 [+ 새 고객(반려견)] (또는 [+] → 새 고객 · 반려견). 반려견 이름과 연락처(필수)만 넣고 저장 → 이어서 나오는 [예약 등록]을 누릅니다 ([상세 보기]로 나머지 정보를 넣어도 됨).
  4. 날짜부터 정하려면 예약 탭 달력에서 날짜를 누르고 [+ 이 날짜에 예약 추가].
  5. 반려견을 고르면 그 아이 몸무게 기준 서비스별 가격과 예상 금액이 보입니다 (예약 폼에는 몸무게 칸이 없고, 몸무게는 미용 기록에서 적음). 시간이 겹치거나 휴무일이면 저장 전에 한 번 묻습니다.
  6. 저장하면 토스트 한 줄에 [문자 보내기]가 약 8초 붙습니다 (보호자 전화번호가 있을 때). 누르면 예약 확인 문자가 채워집니다.

취소·노쇼 예약의 날짜나 시간을 바꾸면 원래 건은 이력으로 그대로 남고 새 예약(대기)이 생깁니다.

미용 완료

  1. 홈이나 예약 화면의 예약 카드에서 [미용 완료]를 누릅니다 (예약 없이 온 손님은 [+] → 새 미용기록, 고객 상세의 + 미용 기록은 가장 최근에 온 반려견이 미리 골라짐). 폼을 여는 것만으로는 예약 상태가 바뀌지 않고, 기록을 저장하면 예약이 완료가 됩니다.
  2. 오늘 몸무게를 확인하고 서비스를 고르면 구간 가격이 자동으로 들어갑니다. 단골은 [이전 미용과 같음] 한 번으로 서비스·가격·스타일이 채워집니다 (새 기록에서만 보임).
  3. 값을 받지 않은 항목은 기본가 아래 서비스로 제공 링크를 눌러 나오는 [서비스 제공] 토글을 켭니다. 금액에서 빠지고 "서비스로 제공한 금액"에 따로 잡힙니다. 메뉴에서 무료로 등록한 서비스는 자동으로 서비스 제공이 됩니다.
  4. 결제 수단을 고릅니다: 카드 · 현금 · 계좌이체 · 미결제. 정액권 잔액이 있는 손님은 [정액권]이 자동으로 골라지고, 잔액이 모자라면 나머지 금액의 결제 방법을 묻습니다 (정액권).
  5. 필요하면 컨디션·협조도·메모와 전·후 사진(2장)을 넣고 저장합니다.

몸무게 칸은 "몸무게 구간 사용 안 함"이면 숨겨지고, 고른 서비스가 모두 단일가이고 반려견 몸무게가 있으면 상세 옵션 안으로 들어갑니다.

저장 직후: 문자 · 리포트 · 다음 예약

  • 저장하면 "미용 기록 저장 완료" 토스트 한 줄에 [문자 보내기]가 붙습니다 (보호자 전화번호가 있을 때). 누르면 미용 완료 문자가 채워집니다.
  • 리포트는 미용 기록 목록에서 그 기록의 [보호자에게 보내기]로 보냅니다.
  • 리포트 화면의 [다음 예약 등록 (날짜)]을 누르면 다음 미용 추천일이 들어간 예약 창이 열립니다. 추천일은 반려견 미용 주기로, 주기가 없으면 설정의 재방문 기준일(기본 30일)로 계산합니다.

마감 정산

  1. 더보기 → 매출 → 오늘 탭에서 오늘 매출과 결제 수단별 합계를 봅니다.
  2. 미결제이 있으면 홈의 미결제 현황 카드에서 처리합니다 (돈 관리).
  3. 종이로 남기려면 [일일 정산표]를 누릅니다.

3. 손님 연락

문자 버튼을 누르면 앱이 문구를 채워 휴대폰 문자 앱을 열어 줍니다. 보내기는 문자 앱에서 직접 누르세요.

예약 리마인더

홈의 다음 영업일 예약 리마인더 카드에서 손님마다 [문자]를 누릅니다. 내일이 휴무일이면 다음 영업일까지의 예약을 모아 보여 줍니다. 예약 화면의 예약 카드에 있는 [재확인 문자]로도 보낼 수 있습니다.

연락할 손님

홈의 연락할 손님 카드는 탭 3개로 나뉩니다.

  • 올 때 됨·늦음 — 미용 주기가 지난 반려견 (문자·전화·예약·제외)
  • 오래 안 옴 — 주기의 2배 넘게 안 온 반려견. 다시 안 올 손님은 "제외"
  • VIP — 재방문 알림 기준일(기본 30일) 넘게 안 온 VIP

문자·전화를 누르면 "연락함"으로 표시되고 잠시 목록에서 내려갑니다. 앞으로 예약이 잡힌 손님은 자동으로 빠집니다.

미결제 문자

홈 미결제 현황 카드의 [문자]를 누르면 반려견 이름·날짜·금액이 들어간 정중한 안내 문구가 채워집니다. 돈을 받으면 같은 줄의 [결제]를 누르세요.

생일 문자

7일 안에 생일인 손님·반려견이 홈에 뜹니다. 반려견은 생일을 입력한 경우만 뜹니다 (나이만 넣으면 안 뜸).

문자 문구 고치기

  1. 설정 → 운영 설정 → 메시지 템플릿.
  2. 고칠 문구(예약 확인·미용 완료·미결제 안내 등 10가지)를 고릅니다.
  3. {반려견명} 같은 변수는 수정 화면의 변수 버튼으로 넣습니다. 보낼 때 실제 이름·날짜로 바뀝니다.

문구 10가지와 변수 목록은 부록 › 화면별 상세 설명에 있습니다.

4. 돈 관리

매출과 받은 돈

더보기 → 매출 → 이번 달 탭 맨 위에 두 숫자가 나란히 나옵니다.

  • 이번 달 매출 — 미용한 날 기준, 미결제 포함 (세금 신고 기준)
  • 받은 돈 — 이번 달에 실제로 들어온 돈 (정액권 충전 포함)

그 아래 이번 달 받은 돈 · 결제 수단별 표는 받은 돈 기준이라 정액권 충전·환불이 수단별 줄로 들어갑니다. 정액권 사용과 미결제는 합계 밖 참고 줄입니다.

설정 → 운영 설정에 매출 목표와 고정비를 넣으면 목표 진행률과 순이익(받은 돈 기준)이 나옵니다. 지난달 데이터가 없으면 페이스·손익 카드 대신 한 줄 안내만 나옵니다. 요일별·월별 추이는 매출 화면 맨 아래 "자세한 분석 보기"에서 봅니다.

미결제

결제 수단을 "미결제"로 저장한 기록은 아직 돈을 받지 않은 것으로 남습니다. 홈 미결제 현황 카드에 5건까지 보이고, 더 있으면 "전체 N건 보기 →"로 미용 기록 목록에서 다 봅니다. [문자]로 안내하고, 받으면 [결제]로 결제 수단을 정합니다. 이번 달 탭의 "미결제 N건"을 눌러도 홈으로 갑니다.

정액권 (선불 충전)

손님이 미리 돈을 맡기고 미용할 때마다 차감하는 금액형 정액권입니다. 한 보호자의 잔액을 그 집 반려견이 함께 씁니다. 쓰지 않으면 화면에 아무것도 늘어나지 않습니다.

  1. 충전: 고객 상세의 반려견 아래 '정액권' 칸에서 [충전] (내역이 없으면 "정액권 잔액 0원 · 충전" 한 줄). 받은 금액, 보너스([+5%]·[+10%]), 결제 방법을 고르면 충전 후 잔액이 보입니다. 예: 30만원 + 보너스 3만원 → 잔액 33만원.
  2. 사용: 잔액이 있는 손님은 미용 기록의 결제 수단에 [정액권]이 자동으로 골라집니다. 합계만큼(모자라면 잔액만큼) 차감되고, 모자라면 "잔액 N원 — 나머지 M원은?"에서 현금·카드·계좌이체·미결제 중 고릅니다. 영수증에 '정액권 사용 -N원 (잔액 M원)'이 찍힙니다.
  3. 환불: '환불 금액' 한 칸만 적습니다. 보너스를 빼고 돌려줬을 때처럼 실제 돌려준 금액이 다르면 접힌 '실제 돌려준 금액이 다르면'을 열어 적습니다.
  4. 조정: 종이 장부 잔액을 옮길 때처럼 돈이 오가지 않을 때만. 이유(메모)를 꼭 적습니다.
  • 기록 금액을 고치거나 고객을 바꾸면 저장할 때 차감액을 다시 계산하고, 기록을 지우면 쓴 금액이 잔액으로 돌아갑니다.
  • 내역 줄을 누르면 고치거나 지울 수 있습니다 ('사용' 줄은 그 미용 기록이 열림).
  • 잔액이 남은 손님은 삭제할 수 없습니다. 먼저 환불(또는 조정)로 0원을 만드세요. 반려견을 다른 보호자에게 옮겨도 잔액·내역은 원래 보호자에게 남습니다.
  • 매출은 미용한 날 기준이라 정액권으로 낸 미용도 그날 매출입니다 (충전한 날은 매출이 아님). 받은 돈은 충전한 날 받은 돈을 더하고, 환불은 빼고, 정액권으로 낸 몫은 뺍니다.
  • 이번 달 탭에 '정액권: 이번 달 충전 N원 · 남은 잔액 합계 M원' 줄이 보입니다 (정액권을 쓴 적이 있을 때만). 결제 수단별 표에는 충전·환불이 수단별 줄로 들어갑니다.
  • 백업·복원·동기화에 정액권 장부도 들어갑니다. 정액권 이전의 옛 백업을 복원하면 내역이 비워지고, 동기화하는 다른 기기도 앱을 최신으로 업데이트해야 정액권이 보입니다.

예약금

  • 예약금은 정액권 충전으로 받고, 충전 창의 메모 칩 [메모: 예약금]을 누릅니다. 예약 메모에도 "예약금 2만 받음"처럼 적어 두세요.
  • 손님이 오면 미용 기록 결제에서 정액권을 쓰고 나머지를 받습니다.
  • 노쇼로 돌려주지 않으면 정액권 조정 → [노쇼 예약금 (돌려주지 않음)]. 돌려주면 환불.
  • 예약금은 받은 날 '실제 받은 돈'에 들어갑니다. 노쇼 예약금은 '이번 달 매출'에 들어가지 않고, 매출 화면 정액권 줄의 '조정으로 줄인 잔액'에서 봅니다 (세무 처리는 세무사에게 확인).

서비스로 제공한 금액

미용 기록에서 [서비스 제공]으로 켠 항목의 원래 가격 합계입니다. 매출에는 들어가지 않고, 이번 달 탭과 분석 화면에 "서비스로 제공한 금액 (매출 제외)"으로 따로 보입니다. 영수증에는 줄 그은 가격과 "서비스"로 찍힙니다.

세무 자료

  1. 설정 → 데이터 → [세무 자료 내보내기] (매출 화면 맨 아래 링크로도 갑니다).
  2. 기간을 고르고 [CSV 다운로드].
  3. 파일을 세무사에게 보내거나 엑셀로 엽니다 (엑셀에서 열기).

미용 한 건이 한 줄입니다. 칸: 거래번호 · 날짜 · 구분(미용(그루밍)/목욕) · 고객명 · 펫이름 · 결제수단 · 공급가액 · 현금영수증(Y/N) · 현금영수증번호 · 서비스명 · 미용사 · 메모 · 기록번호.

  • 정액권으로 낸 미용은 결제수단에 '정액권'(또는 '정액권 20000+카드')으로 적힙니다 — 정액권 매출은 쓴 날 잡힙니다.
  • 정액권 충전·환불, 노쇼 예약금은 미용 줄 아래에 따로 나옵니다 (거래번호가 P-로 시작, 매출 아님 — 참고용). 내보내기 창에 "정액권 충전 N건 · 환불 N건 · 노쇼 예약금 N건"이 보입니다.
  • 10만원 이상 현금 충전은 받은 날 현금영수증 의무가 있습니다 — 앱은 충전의 현금영수증 발행 여부를 따로 저장하지 않으니 직접 챙기세요.
  • 같은 기간을 다시 내보내도 됩니다. 기록을 고쳤다면 월말에 그달 전체를 한 번 더 내보내 세무사·장부에 다시 주면 최신으로 맞춰집니다.

맥의 세무장부(비서 폴더)로 가져올 때: 받은 CSV를 비서 폴더에 넣고 매출가져오기.command를 더블클릭합니다. 현금영수증·정액권·미결제 처리, 다시 가져올 때 고쳐지는 방식은 그 폴더의 매출_가져오기_사용법.md에 있습니다.

5. 사진

사진은 세 가지 용도가 다릅니다.

종류용도앱에 저장?
기록 사진 (전·후)다음 미용 때 "지난번엔 어떻게 했지?" 확인예 (반려견별 최근 3회)
미용 리포트오늘 미용 결과를 보호자에게아니요 (보내기만)
사진 카드첫 미용·생일·이벤트 때 꾸며서 공유아니요 (폰 저장·공유만)

기록 사진

미용 기록에 전·후 2장을 넣습니다. 반려견 상세 맨 위 "최근 미용 사진" 줄에서 모아 봅니다. 기본은 반려견별 최근 3회만 남고 오래된 사진은 자동 정리됩니다 (글 기록은 남음). 보관 회차는 설정 → 데이터 → 기록 사진 보관에서 2회·3회·5회·전부 중 고릅니다. 2년 넘게 안 온 반려견은 어떤 설정이어도 마지막 방문 사진만 남습니다 (하루 한 번 자동, 기기 용량이 계속 늘지 않게).

미용 리포트

  1. 미용 기록 목록에서 그 기록의 [보호자에게 보내기] (고객 상세의 최근 기록에서도 됨).
  2. 전·후 사진, 오늘 한 것, 오늘 상태, 미용사 한마디, 집에서 관리법, 다음 미용 추천일이 이미지 한 장으로 만들어집니다 (빈 항목은 빠짐).
  3. 카톡·문자로 보냅니다. 리뷰 링크를 넣어 두었으면 하단에 "리뷰 남겨주시면 큰 힘이 돼요"가 붙습니다.

사진 카드

  1. 더보기 → 사진 카드, 또는 미용 기록 카드의 [사진 카드] (그 기록의 사진·서비스·다음 방문일이 미리 채워짐).
  2. 반려견(선택)과 날짜를 확인하고 "사진 골라서 카드 만들기"를 누릅니다.
  3. 사진 칸을 눌러 1~4장을 고릅니다.
  4. 아래 탭(사진 · 틀 · 꾸미기 · 스티커 · 글자)으로 레이아웃·테마·스티커·글자를 고르면 위 미리보기가 바로 바뀝니다.
  5. "완성하기" → 공유하기(카톡·문자·인스타) 또는 저장.

레이아웃·스티커·글꼴 설명과 나만의 프레임·스티커 만들기는 부록 › 사진 카드 · 프레임 · 스티커에 있습니다.

6. 데이터 지키기

데이터는 이 기기 안에 있습니다

동기화를 켜지 않은 채 기기를 바꾸거나 브라우저 데이터를 지우면 데이터가 사라집니다. 동기화를 켜도 백업은 계속 하세요. 한 기기에서 지우면 다른 기기에서도 지워지기 때문입니다.

기기 간 동기화

휴대폰과 컴퓨터에서 같은 데이터를 보는 기능입니다. 사장님 계정의 클라우드(Firebase)를 쓰며, 무료 범위 안에서 동작하고 카드 등록은 필요 없습니다. 매장에 등록된 계정만 쓸 수 있습니다.

  1. 켜기 전에 백업 파일을 하나 받아 둡니다.
  2. 인터넷이 되는 상태에서 설정 → 데이터 → 기기 간 동기화 → [구글로 동기화 켜기]. 상태가 "동기화됨"이면 완료입니다.
  3. 아이폰처럼 구글 로그인이 안 되는 기기를 쓰려면, 먼저 켠 기기(컴퓨터 등)에서 [다른 기기용 비밀번호 설정]으로 비밀번호(6자 이상)를 만듭니다.
  4. 그 기기에서 [이메일·비밀번호로 켜기] → 같은 구글 이메일과 그 비밀번호를 입력합니다.

처음 연결하면 클라우드 데이터를 받느라 시간이 걸립니다. 하루 무료 사용량이 모자라면 멈췄다가 다음 날 앱을 열 때 이어서 받습니다. 인터넷이 끊긴 동안 고친 내용은 다시 연결되면 자동으로 올라갑니다.

버튼언제 쓰나요
지금 동기화바로 확인하고 싶을 때. 평소엔 자동이라 안 눌러도 됩니다.
전체 다시 맞추기기기끼리 내용이 다를 때만 (아래)
동기화 끄기멈출 때. 이 기기 데이터는 남고, 아직 못 보낸 변경은 보내지 않습니다.

클라우드 사진 용량

동기화로 올라간 미용 사진은 무료 클라우드 공간(1GB)을 씁니다. 설정 → 데이터 → 기기 간 동기화 카드 아래에 "클라우드 사진 약 0.31GB / 1GB (31%)"처럼 어림값이 보입니다.

70%를 넘으면 홈에 한 번 안내가 뜨고(닫으면 30일 동안 안 뜸), 같은 카드에 [오래 안 온 반려견 사진 정리]가 생깁니다. 누르면 2년 넘게 안 온 반려견은 클라우드에 마지막 방문 사진만 남깁니다. 이 기기와 사진을 찍은 기기의 사진은 그대로이고, 자동으로 지우지는 않습니다 — 누를 때만 정리됩니다.

전체 다시 맞추기

다른 기기에서 반려견 이름이 "?"로 보이거나, 한쪽에만 있는 기록이 있을 때 씁니다.

  • 올바른 데이터가 있는 기기에서 누르세요. 이 기기와 클라우드를 비교해 서로 빠진 것을 채웁니다.
  • 데이터를 지우지 않습니다. 양쪽에 다 있으면 더 최근에 고친 쪽으로 맞춥니다.
  • 무료 사용량을 많이 씁니다. 오늘 사용량이 다 차면 멈추고, 다음 날 다시 누르면 이어서 합니다.

백업

  1. 설정 → 데이터 → [백업 (사진 제외 · 권장)]. 날짜·시간이 들어간 JSON 파일이 받아집니다 (수 MB).
  2. 파일을 카톡 나에게 보내기, Google Drive, iCloud 등 기기 밖에 보관합니다.

주 1회 이상, 데이터가 많을수록 자주 하세요. 사진까지 남기려면 [사진 포함 백업 (용량 주의)] — 수백 MB가 될 수 있습니다. 동기화가 정상이면 홈에 백업 경고가 뜨지 않고, 한 달에 한 번 가벼운 안내만 나옵니다.

복원 · 되돌리기

  1. 설정 → 데이터 → [데이터 복원하기] → 백업 파일(JSON) 선택.
  2. 확인 문구를 읽고 진행합니다. 지금 데이터는 덮어써지고, 동기화가 켜져 있으면 다른 기기에도 그대로 반영됩니다.
  3. 잘못 복원했다면 7일 안에 같은 칸의 [복원 전 상태로 되돌리기]를 누릅니다.
  • 되돌리면 복원 뒤에 새로 넣거나 고친 예약·기록은 사라집니다 (동기화 중이면 다른 기기에서도).
  • 사진 포함 백업으로 복원했다면 사진은 되돌려지지 않습니다.

폰을 바꿀 때 (기기 옮기기)

헌 폰은 새 폰에서 데이터를 확인할 때까지 지우지 마세요. 아래 순서대로 하면 손님·예약·기록·정액권이 그대로 옮겨집니다.

① 헌 폰에서 (옮기기 전)

  1. 설정 → 데이터 → [백업 (사진 제외 · 권장)]을 받아 카톡 나에게 보내기·iCloud·Google Drive 등 폰 밖에 둡니다. 동기화를 쓰고 있어도 만일을 위해 받아 둡니다.
  2. 동기화를 쓰고 있다면 설정 → 데이터 → 기기 간 동기화가 "동기화됨"인지 확인합니다. 아니면 [지금 동기화]를 누르고 기다립니다.
  3. 아이폰에서 동기화를 이메일·비밀번호로 켰다면 그 이메일과 비밀번호를 확인해 둡니다. 모르면 컴퓨터에서 [다른 기기용 비밀번호 설정]으로 새로 만듭니다.
  4. 보안 잠금(마스터 코드)을 쓰고 있다면 마스터 코드를 확인해 둡니다. 잊었다면 종이에 적어 둔 복구 코드를 씁니다.

② 새 폰에서

  1. 사파리로 앱 주소(a01090037052-lab.github.io/pet-salon)를 엽니다. 카톡 등으로 주소를 보내 두면 편합니다.
  2. 사파리 아래 [공유 → 홈 화면에 추가]로 앱을 만들고, 앞으로는 홈 화면의 앱 아이콘으로만 엽니다 (사파리 탭과 홈 화면 앱은 데이터가 따로입니다).
  3. 잠금 화면이 뜨면 마스터 코드를 넣습니다.
  4. 동기화를 쓰는 경우: 설정 → 데이터 → 기기 간 동기화 → [이메일·비밀번호로 켜기] → 같은 이메일·비밀번호. 처음에는 데이터를 받느라 몇 분 걸립니다. 하루 무료 사용량이 차면 다음 날 앱을 열 때 이어서 받습니다.
  5. 동기화를 안 쓰는 경우: 받아 둔 백업 파일을 새 폰에 저장(파일 앱)한 뒤 설정 → 데이터 → [데이터 복원하기] → 그 파일을 고릅니다.
  6. 확인: 고객 수·최근 기록·다가오는 예약·정액권 잔액이 헌 폰과 같은지 몇 개 비교합니다.
  7. 예약 알림: 동기화가 "동기화됨"이 된 뒤에 설정 → 운영 설정 → 알림 설정 → [이 기기에서 알림 받기] → 알림 허용 → [시험 알림 보내기]로 확인합니다. 동기화가 끝나기 전에 누르면 "알림 열쇠가 맞지 않아요"가 나올 수 있으니 잠시 뒤 다시 누르세요.
  8. 직접 만들어 넣은 사진 카드 틀·스티커는 이 기기에만 저장되어 옮겨지지 않습니다. 필요하면 새 폰에서 다시 넣습니다. (매장 정보·로고·서비스 메뉴·문자 문구는 동기화·백업으로 옮겨집니다.)

③ 헌 폰 정리 (새 폰 확인 뒤)

  1. 헌 폰 앱에서 설정 → 운영 설정 → 알림 설정 → [이 기기 알림 끄기]. (깜빡하고 지워도 다음 예약 알림을 보낼 때 알림 서버가 저절로 정리합니다.)
  2. 보안 잠금을 쓴다면 설정 → 보안 → [이 기기 등록 해제].
  3. 홈 화면의 앱 아이콘을 길게 눌러 삭제하고, 아이폰 설정 → 앱 → Safari → 고급 → 웹사이트 데이터에서 이 주소의 데이터를 지웁니다. 앱 안의 [모든 데이터 삭제]를 눌러도 클라우드 데이터는 지워지지 않습니다(이 기기만 지워짐).

컴퓨터를 바꿀 때도 같습니다: 새 컴퓨터에서 앱 주소를 열고 → [구글로 동기화 켜기] → 확인 → [이 기기에서 알림 받기].

아이폰 7일 주의 · 인터넷 없을 때

  • 아이폰은 홈 화면에 추가하지 않고 사파리 탭으로만 쓰다가 7일 넘게 안 열면 데이터를 지울 수 있습니다. 홈 화면에 추가하지 않은 아이폰에는 홈에 안내가 뜹니다 (닫으면 90일 뒤 다시).
  • 한 번 열어 둔 앱은 인터넷 없이도 등록·예약·기록·매출·백업이 모두 됩니다. 끊기면 화면 위에 빨간 "오프라인" 배너가 뜨고, 다시 연결되면 "온라인 복귀" 알림과 함께 사라집니다.
  • 문자 앱은 열리지만 발송에는 통신망이 필요하고, 앱 업데이트는 인터넷이 연결될 때 확인합니다.

7. 자주 묻는 질문

Q. 앱이 안 열려요

새로고침(F5 또는 Ctrl+R) → 브라우저 캐시 삭제 후 다시 접속 → 다른 브라우저 → 기기 재시작 순서로 해 보세요.

Q. 데이터가 사라졌어요

데이터는 접속한 주소·브라우저마다 따로 저장됩니다. 1) 평소 쓰던 정확한 주소인지, 2) 홈 화면에 추가했다면 그 아이콘으로 열었는지 확인하세요. 그래도 없으면 동기화를 다시 켜거나 백업 파일로 복원합니다.

Q. 기기마다 보이는 내용이 달라요

올바른 데이터가 있는 기기에서 설정 → 데이터 → [전체 다시 맞추기]를 누르세요. 데이터는 지워지지 않습니다.

Q. 문자가 안 보내져요

앱은 문구를 채워 문자 앱을 열어 줄 뿐이고, 발송은 휴대폰 문자 앱이 합니다. 손님 연락처가 맞는지, 휴대폰 문자 권한이 허용됐는지 확인하세요. +82로 시작하는 번호와 0505 안심번호도 정상 동작합니다.

Q. 예약이 겹친다고 나와요

같은 미용사나 같은 반려견의 시간이 겹치면 "그래도 저장할까요?", 휴무일이면 "그래도 예약할까요?"라고 한 번 묻습니다. 괜찮으면 그대로 저장하세요. 같은 반려견의 같은 날짜·같은 시각 예약만 저장되지 않습니다.

Q. 가격이 자동으로 안 들어가요

미용 기록의 오늘 몸무게가 비어 있으면 구간 가격을 넣지 않습니다. 몸무게를 넣으면 "5.2kg → 5~7kg 구간 50,000원"처럼 근거와 함께 들어갑니다.

Q. 예약 알림이 안 와요

예약 알림은 앱을 닫아도 옵니다. 다만 받을 기기마다 한 번 설정 › 운영 설정 › 알림 설정에서 [이 기기에서 알림 받기]를 눌러 허용해야 해요. 켠 뒤 [시험 알림 보내기]로 바로 확인할 수 있습니다.

  • 아이폰은 사파리에서 [공유 › 홈 화면에 추가]로 만든 앱에서만 됩니다 (iOS 16.4 이상). 사파리 탭에서는 안 와요.
  • 아이폰 설정 › 알림 › 펫살롱이 꺼져 있으면 오지 않아요. 집중 모드(방해 금지)도 확인해 주세요.
  • 알림 목록은 인터넷이 될 때 올라갑니다. 예약을 오프라인으로 바꿨다면 연결된 뒤 한 번 앱을 열어 주세요.
  • 알림에는 반려견 이름·시간·서비스만 나오고, 보호자 이름·번호는 나오지 않아요.
Q. 저장 공간이 부족하다고 해요

설정 → 데이터 → [저장 공간 최적화]를 누르고, 같은 카드의 기록 사진 보관을 최근 2회로 줄이세요 (글 기록은 남음). 백업 파일은 다른 곳에 옮겨 두세요. v196부터 만든 사진 포함 백업은 복원할 때 파일을 조각으로 읽어 수백 MB여도 휴대폰에서 복원됩니다 (그 전 파일은 컴퓨터에서 복원을 권함).

Q. 반려견을 지워도 되나요?

지우면 그 아이의 예약·미용 기록·사진이 함께 지워지고 매출 통계에서도 빠집니다 (되돌릴 수 없음). 사망·양도라면 삭제 대신 반려견 상태를 바꾸세요. 지워야 한다면 먼저 백업하세요.

Q. 비용이 드나요?

무료입니다. 광고·구독료가 없고, 인터넷 요금만 듭니다.

8. 부록

필요할 때 펼쳐 보세요.

가격 구간 · 서비스 가격 자세히

서비스 가격은 매장 공통 몸무게 구간표 하나를 따릅니다. 설정 → 운영 설정 → 가격 구간 카드의 [구간 편집], 또는 서비스 메뉴 위의 [몸무게 구간] 줄로 엽니다. 열 때 숫자 키패드가 바로 올라오지 않습니다.

샵 유형별 설정 요령

  • 몸무게와 상관없이 한 가격: 설정 › 가격 구간 › '구간 사용 안 함'을 켭니다. 그러면 기록 폼에 몸무게 칸이 없고 서비스 폼은 이름·분류·가격만 남습니다.
  • 소·중·대 3단계: 구간 편집 › 3단계 프리셋(~5 / ~10 / 10kg~)을 고르고, 경계는 숫자만 고칩니다.
  • 견종별 가격: 구간을 끄고 '전체미용 (비숑·코커)'처럼 견종을 이름에 적어 단일가 서비스로 등록합니다. 기록 폼에서 견종을 치면 바로 찾히고, 그 반려견 견종이 이름에 있는 서비스가 위로 옵니다.
  • 목욕 전문 + 옵션 많은 샵: 옵션은 분류 '추가 옵션'으로 등록하면 kg당 추가 요금이 붙지 않습니다. '저장하고 이어서 등록'이 분류와 단일가를 유지하고, 기록 폼의 추가 항목 목록에는 등록한 옵션이 모두 나옵니다.
  • 대형견 샵: 구간 경계를 40kg까지 올리고 kg당 추가 요금 기준도 함께 올립니다. 몸무게 확인창은 구간표에 맞춰 뜹니다.
  • 부분미용 샵: 얼굴컷·발컷 등은 '단독 케어'로 등록하면 주 서비스로도 추가 항목으로도 고를 수 있습니다. 코스에 얹는 얼굴 모양(테디컷 등)은 '스타일 추가'로 등록하면 기록 폼에 칩으로 나옵니다.
  • 고양이: 종류 칸이 없으니 '고양이 목욕'처럼 이름에 적고 단일가로 둡니다. 강아지 구간 서비스를 잘못 고르지 않도록 주의하세요.
  • 할증(털엉킴·사나움·노견): '추가 옵션'으로 등록합니다. 두 번째 방문부터는 '이전 미용과 같음'이 추가 항목까지 복원합니다.
  • 상담 후 결정하는 서비스: 가격을 비워 두면 '가격 미입력'으로 저장되고 기록 때 직접 적습니다. 최저가가 있으면 '~부터'를 씁니다.

구간 규칙

  • 기본 5단계: ~3kg / 3~5kg / 5~7kg / 7~10kg / 10kg~. 경계 몸무게는 아래 구간에 들어갑니다 (5kg → 3~5kg, 5.1kg → 5~7kg).
  • 빠른 설정: 3단계(~5 / ~10 / 10kg~) 또는 5단계. 3단계의 경계는 숫자만 고치면 됩니다. 구간을 중간에 끼우면 새 구간은 가벼운 쪽 이웃 구간 가격을 복사해 시작하고, 저장 전에 서비스별 "이전 → 이후" 가격이 확인창에 나옵니다. 서비스 등록 폼의 분류 칩 아래에는 분류 차이를 설명하는 힌트 한 줄이 있습니다.
  • 구간 추가·삭제·경계 수정: 각 구간의 "최대 몸무게"를 고칩니다. 마지막 구간은 항상 "그 이상 전부". 경계만 바꾸면 가격은 그대로입니다 ("구간 경계를 저장했어요 (가격은 그대로)"). 가격이 든 구간을 지우면 몇 개 서비스에 가격이 있는지 보여 주고 묻습니다.
  • 초과 kg 추가 요금: 기본 켜짐 — 10kg 넘으면 1kg당 +5,000원, 소수 kg은 올림 (10.3kg → +5,000원, 12.3kg → +15,000원). 추가 요금은 입력한 금액 그대로 붙습니다. 기준 kg은 마지막 구간 시작보다 낮게 정할 수 없어(마지막 구간 경계를 바꾸면 기준도 맞춰짐) 그 앞 구간에는 붙지 않습니다. 끌 수 있습니다.
  • 반올림 단위: "한 번에 채우기"와 서비스 메뉴의 일괄 조정에만 적용됩니다. kg당 추가 요금에는 적용되지 않습니다.
  • 몸무게 없이 사이즈만 있는 반려견: 소형은 4kg, 중형은 9kg, 대형은 20kg이 속한 구간 가격으로 계산하고(기본 5단계에서는 3~5kg · 7~10kg · 10kg~) "몸무게를 입력하면 정확해요"라고 알려 줍니다.

몸무게 구간 사용 안 함 (모든 서비스 단일가)

구간표 맨 위를 체크하면 구간 칸이 모든 화면에서 숨겨지고 새 서비스는 단일가로 만들어집니다. 이미 구간 가격으로 적은 서비스는 단일가가 적혀 있으면 그 값, 없으면 첫(가장 가벼운) 구간 가격을 받습니다. 켤 때 "전체미용 4만~6만 → 40,000원 단일가"처럼 바뀌는 가격을 보여 주고 확인합니다. 구간 가격은 지우지 않고 보관하므로 다시 켜면 그대로 돌아옵니다. 이 상태에서는 매장 기본 kg당 요금을 쓰지 않습니다 (서비스별 "이 서비스만 따로" 요금은 계속 붙고, 확인 화면에 그렇게 표시됨).

큰 아이 추가 요금 (서비스별)

  • 서비스 수정 창의 "더 보기"에서 매장 기본(구간표의 kg당 요금) / 추가 요금 없음 / 이 서비스만 따로(예: 10kg 넘으면 1kg당 +7,000원) 중 고릅니다.
  • 처음 값은 분류로만 정해집니다: 미용 코스는 매장 기본, 추가 옵션·단독 케어는 없음. 이름은 보지 않습니다.
  • 단일가 서비스에는 매장 기본 추가 요금이 붙지 않습니다. 큰 아이에게 더 받으려면 "이 서비스만 따로"를 고르세요.
  • 요금이 붙는 서비스만 목록 카드 셋째 줄에 "10kg 넘으면 1kg당 +7,000원"처럼 보입니다.

구간별 가격 입력

  • 구간 수만큼 가격 칸이 나옵니다. 접힌 "한 번에 채우기"를 열어 첫 구간 가격을 넣고 [채우기]를 누르면 "구간마다 +5,000원"(바꿀 수 있음)씩 올려 채웁니다.
  • 일부 구간만 적고 저장하면 "빈 구간을 어떻게 할까요?" — [앞 구간 가격으로 채우기] / [모두 같은 가격(단일가)] / [취소]. 예전에 비워 둔 구간은 앞 구간 가격을 쓰고 "(앞 구간 가격)"으로 표시됩니다.
  • 모든 구간을 같은 값으로 적어도 단일가로 몰래 바꾸지 않습니다. 몸무게와 상관없는 서비스는 "모든 몸무게 같은 가격 (단일가)"를 체크하세요.
  • 목록 카드에는 "3.5만~5.5만"처럼 범위만 보이고, 구간별 가격은 카드를 눌러 봅니다. 끝의 "~"는 "'~부터'로 표시"를 켠 서비스에만 붙습니다.

미용 기록·예약·영수증에서 가격이 정해지는 방식

  • 예약 폼: 몸무게 칸은 없습니다. 반려견 프로필 몸무게로 서비스 칩에 구간 가격과 구간 이름(예: "5~7kg", 초과 요금이 붙으면 "초과 3kg 포함"), 아래에 예상 금액 합계가 나옵니다. 몸무게를 모르면 "3.5만~5.5만" 같은 범위가 보입니다.
  • 미용 기록: 오늘 몸무게(서비스·기본가보다 위)는 지난 몸무게가 미리 들어갑니다. 바꾸면 기본가·추가 항목 가격이 다시 계산되고 "5.2kg → 5~7kg 구간 50,000원"처럼 근거가 보입니다 (초과 요금 계산, "(앞 구간 가격)" 포함). 기록을 고칠 때도 이 줄이 보이고, 지금 메뉴 가격과 다르면 알려 줍니다.
  • 몸무게가 구간표 마지막 경계의 1.5배(최소 30kg)를 넘거나 직전 몸무게에서 50% 넘게 바뀌면 오타인지 한 번 묻습니다 (바로 저장해도 저장 전에 묻고, 이미 "맞아요"를 고른 같은 값은 다시 묻지 않음). 기록 폼의 추가 항목 태그에는 금액이 보입니다. 프로필과 다르면 "반려견 몸무게도 업데이트"(새 기록은 기본 체크)가 나옵니다.
  • 기본가를 직접 고친 뒤 구간이 바뀌면 설명 줄 옆에 "구간 가격(55,000원) 적용" 링크가 나옵니다.
  • 저장할 때 그날 몸무게·구간·메뉴 가격이 기록에 남아, 나중에 구간표나 메뉴 가격을 바꿔도 그대로입니다.
  • 영수증: "전체미용 · 5.2kg (5~7kg) 50,000원", 초과 요금은 "+ 초과 3kg × 5,000원 15,000원"처럼 따로 한 줄 (메뉴 가격 그대로 받은 경우).

예전 소형·중형·대형 가격은?

이 버전으로 처음 열면 자동으로 바뀝니다: 소형 → ~3·3~5·5~7kg, 중형 → 7~10kg과 10kg~ (10kg 초과분은 초과 kg 요금이 더해짐). 큰 아이 추가 요금이 붙지 않는 서비스(추가 옵션·단독 케어)는 마지막 구간(10kg~)이 예전 대형 가격을 받습니다. 바뀐 직후 "가격 구간이 5단계로 바뀌었어요" 안내가 한 번 나오니 구간과 가격을 확인하세요. 예전 백업을 복원해도 같은 방식으로 바뀝니다. 아직 업데이트하지 않은 다른 기기에서 가격을 고치면 이 기기가 그 값을 구간 가격에 반영하고 알려 줍니다. 큰 아이 추가 요금 규칙이 없던 서비스에는 분류에 따라 처음 값이 정해집니다. 예전 버전에서 이름 때문에 "없음"이 된 미용 코스는 그대로 남으니, 서비스마다 "더 보기"에서 확인하세요.

사진 카드 화면

  • 반려견 고르기(선택): 이름이 카드에 들어가고, 보호자 번호로 문자를 열 수 있으며, "○○ 기록 사진 넣기"로 최근 기록 사진을 가져옵니다.
  • 사진 칸: 작은 칸 4개 한 줄. [여러 장 고르기]로 사진첩에서 한 번에 최대 4장을 고르면 빈 칸부터 채워집니다 (칸을 눌러 여러 장 골라도 그 칸부터 채움). ×로 빼고, "위치"로 위치·확대를 맞춥니다. 고른 장수에 맞는 레이아웃에 "추천"이 붙습니다. 휴대폰에서는 창이 화면 가득 열리고, 미리보기 오른쪽 아래 ⤢로 크게 볼 수 있습니다.
  • 사진 느낌: 사진 칸 아래 원본 · 흑백 · 뽀샤시 · 필름 · 따뜻하게 · 시원하게. 첫 사진으로 견본이 보이고, 고르면 모든 칸에 같이 들어갑니다 (포토부스처럼).
  • 틀(레이아웃): 네컷 세로 · 피드(4:5) · 스토리(9:16) · 2컷 · 폴라로이드. 바꿔도 고른 사진은 그대로입니다. 피드·스토리는 2장 나란히, 3장 위 1칸 + 아래 2칸, 4장 2×2로 자동 분할. 네컷은 칸보다 적게 고르면 칸 수가 줄어 크게 나옵니다. 폴라로이드 모양: "아래 여백 넓게(4:5)"는 진짜 폴라로이드처럼 아래에 이름·큰 제목을 크게 넣고(인스타 피드 비율), "정사각(1:1)"은 여백을 얇게 둡니다.
  • 꾸미기: 테마(클래식 · 필름 · 파스텔 · 다크 · 커스텀 · 내 프레임), 색, 배경, 글꼴. 커스텀은 화이트·베이지·로즈·네이비·민트 빠른 조합, 배경색·글자색·포인트색 직접 선택, 배경 이미지 업로드가 됩니다.
  • 글꼴(19종, 모두 무료·홍보물 사용 가능): 기본 · 고운돋움 · 주아 · 도현 · 개구 손글씨 · 나눔펜 · 고운바탕 · 페이퍼로지 · 감자꽃 · 하이멜로디 · 싱글데이 · 동글 · 베이글 · 검은고딕 · 가석 · 오르빛 · 연성 · 나눔붓 · 독도. 꾸미기 탭 글꼴은 틀의 글자(이름·날짜 등)에, 글자 탭 글꼴은 그 글자에만 쓰입니다. 처음 쓸 때 인터넷으로 한 번 받고, 그 뒤로는 오프라인에서도 됩니다.
  • 글자 탭: ① 글자 넣기 — 글자를 쓰고(세 줄까지, 자주 쓰는 문구 버튼) 모양(글자만·테두리·배경 상자·반투명·말풍선·라벨·네온)·색(12가지)·글꼴을 고른 뒤 [글자 붙이기]. 스티커처럼 어느 틀·내 프레임에든 붙고, 미리보기에서 끌어 옮기고 크기·회전을 바꿉니다. 붙인 글자를 누르면 다시 고칠 수 있고, 마지막 모양·색·글꼴을 기억합니다. 직접 쓴 문구는 최근 8개까지 문구 버튼(보라색)으로 남고(반려견 이름은 다음 손님 이름으로 바뀜), ×로 지웁니다. ② 자동으로 넣는 정보 — 반려견 이름·날짜·매장명·서비스명·다음 방문일. 지금 틀에 자리가 없는 항목은 흐리게 표시되고 안내가 나옵니다 (내 프레임은 정보를 넣지 않음). ③ 틀에 고정된 문구(큰 제목·작은 제목·인사)는 접혀 있습니다. 매장 로고는 설정 → 매장 관리에서 등록 (PNG 투명 배경 권장).
  • 컴퓨터에서는 왼쪽에 큰 미리보기, 오른쪽에 탭이 나옵니다.
  • 완성 화면: 공유하기(카톡·문자·인스타) / 저장 / 인쇄용 4×6 / 인스타 피드·스토리용 저장 / 보호자 번호로 문자 열기 / 다시 꾸미기. 네컷·2컷처럼 긴 카드는 인스타에서 잘리므로 "인스타 피드 4:5"·"인스타 스토리" 버튼으로 테마색(또는 내 프레임)을 배경에 깔고 가운데 놓은 버전을 따로 저장하세요. 모든 레이아웃은 1080px 이상으로 저장됩니다.

스티커

  • 기본 스티커: 스티커 탭 위 묶음 버튼으로 고릅니다 — 레트로(옛 과일 라벨 느낌: SERIOUSLY FLUFFY·TOP DOG·BLEP·BATH TIME! 등 8개) · 브랜드(버건디 손글씨: We Groom, You Smile·Groomed with Love 등 8개) · 모던(검정·흰·코발트: GROOMED 방패·픽셀 강아지·cute mode 등 8개) · 세련된(차분한 배지·라벨·오라 22개: GOOD VIBES·FRESH CUT·오늘 미용 완료 등) · 이모지(Google Noto Emoji, Apache 2.0).
  • 붙이기·고치기: 누르면 미리보기 가운데에 붙습니다. 손가락으로 끌어 옮기고 크기·회전 슬라이더로 맞춥니다. "이 스티커 삭제"·"모두 지우기". 스티커를 고른 동안은 미리보기가 커지고, 스티커는 사진·프레임 위에 찍히며 "다시 꾸미기"로 돌아와도 남아 있습니다. 한 카드에 2~4개, 얼굴·눈을 피해 모서리 쪽이 보기 좋습니다.
  • 글자: 스티커 탭의 "가 글자"를 누르면 글자 탭으로 넘어갑니다 (글자는 글자 탭에서 모양·색·글꼴까지 한곳에서).
  • 내 로고 스티커: 매장 로고를 올려 둔 뒤 "◎ 내 로고" → 그대로(흰 테두리) / 원형 배지(테마 색 원 + 매장명 · GROOMING) / 라벨(크림색 + 매장명). 로고를 바꾸면 다음부터 새 로고로 만들어집니다.
  • 내 스티커: "+ 내 스티커"로 사진첩 그림을 올립니다 (여러 장, 최대 24개). 흰색·단색 배경은 자동으로 지우고 여백을 잘라 냅니다. "내 스티커 정리" → 지울 스티커를 누르면 빠집니다. 이 기기에만 보관됩니다 (동기화 안 함, 백업 파일에는 포함).

내 스티커 만들기 — ChatGPT: 아래처럼 요청하고, 스타일 문장은 고정한 채 주제만 바꾸면 한 세트처럼 통일됩니다. 마음에 드는 그림을 사진첩에 저장해 올리세요.

애견 미용실 사진 카드에 붙일 스티커를 만들어줘. 한 이미지에 스티커 1개, 가운데 배치, 둘레에 굵은 흰색 다이컷 테두리, 배경은 진짜 투명 PNG(체크무늬 금지). 스타일: [레트로 과일 라벨 / 검정·흰·코발트 미니멀 / 버건디·크림 브랜드 손글씨 / 파스텔 귀여운]. 글자는 영어로 정확히: '[문구]'. 주제: [예: 웃는 푸들 얼굴].

캔바·미리캔버스: 정사각 캔버스(예: 1000×1000)에 배치하고 배경을 흰색 한 가지로 둔 채 PNG 저장 (투명 배경 저장이 유료여도 괜찮음 — 앱이 흰 배경을 지움). 그림 바깥이 흰 배경과 닿아 있어야 깔끔히 지워지고, 그림 안의 흰색은 남습니다.

  • 색은 2~3가지, 매장 테마 색 하나를 넣으면 잘 어울립니다. 글자는 영어 2~3단어로 짧게 (AI 그림은 한글이 자주 틀림).
  • 가로·세로 400px 이상으로 만드세요. 체크무늬 배경은 "가짜 투명"이라 안 지워집니다 — "진짜 투명 배경 PNG로 다시"라고 요청하세요.
  • 저작권: 다른 회사 로고·캐릭터(디즈니·산리오 등)나 남의 그림은 쓰지 마세요. ChatGPT·캔바 그림은 대부분 내 홍보물에 쓸 수 있지만, 캔바는 요소의 "상업적 이용 가능" 표시를 확인하세요.

내 프레임 (최대 20개)

  1. 직접 만들기(추천): 설정 → 매장 관리 → 내 프레임 라이브러리 → [직접 만들기]. 추천 스타일(피크닉 체크·블랙 미니멀·Y2K 그라데이션·민트 발자국·레트로 필름·생일 컨페티·벚꽃 도트·크리스마스·밤하늘 반짝·러블리 하트)을 하나 누른 뒤, 칸 배치(네컷 세로·2×2 피드·2컷 세로·1칸 폴라로이드·2×2 스토리) · 배경(단색·그라데이션·무늬·사진) · 사진 칸 모서리·테두리 · 위/아래 글자({매장명}은 매장 이름으로) · 글꼴 · 글자 색 · 글자 뒤 띠 · 매장 로고를 고르고 [내 프레임에 저장]. 칸이 정확히 뚫린 프레임이 만들어져 사진 카드에서 바로 쓸 수 있고, 라이브러리에서 누르면 다시 고칠 수 있습니다.
  2. 그림 올리기: 캔바 등에서 만든 그림은 "내 프레임 라이브러리" → [그림 올리기].
  3. 이름("크리스마스 네컷" 등)과 그림을 넣습니다. 사진이 들어갈 자리를 투명하게 비운 PNG를 고르면 앱이 투명한 칸을 자동으로 찾아 "사진 칸 N개를 찾았어요"라고 알려 주고 방식이 덮기로 바뀝니다 (인생네컷·포토이즘 프레임과 같은 방식).
  4. 덮기 프레임은 크기·칸 수가 자유입니다 — 네컷 세로, 2×2, 피드, 스토리, 하트 모양 칸도 됩니다. 카드 크기는 프레임 그림 비율 그대로 (가로 1080px), 사진은 위에서부터(같은 줄은 왼쪽부터) 순서대로 들어가고, 사진이 칸보다 적으면 돌려 가며 채웁니다. 글자(이름·날짜·매장명)는 그리지 않으니 프레임 그림에 넣거나 글자 스티커로 붙이세요.
  5. 투명한 칸이 없는 그림(JPG 등)은 배경으로 앱의 틀(네컷·피드 등) 뒤에 깔립니다.
  6. 포인트 색·글자 색(배경 방식에서 씀), 활성/비활성을 정하고 저장합니다.
  • 사진 카드 꾸미기 탭 "내 프레임" 줄에 그림 견본과 "사진 N칸"이 나오고, 많으면 옆으로 넘겨 봅니다. 마지막에 쓴 프레임은 다음에 자동 선택됩니다.
  • 세로로 긴 프레임(네컷 등)은 "인쇄용 4×6"에서 두 줄 나란히 + 가운데 자르는 선으로 나옵니다.
  • 라이브러리에서 누르면 편집, 🗑로 삭제, 토글로 활성/비활성 (비활성은 숨김만 — 다음 시즌에 다시 켜기). 프레임 그림은 이 기기에만 저장됩니다.
  • 여러 프레임을 한 세트처럼: 같은 크기(예: 네컷 1080×3240)·같은 칸 위치로 만들고 그림·색만 계절별로 바꾸면 어떤 사진이든 똑같이 잘 맞습니다.

프레임 만들기 — 캔바·미리캔버스(추천): 1080×3240(네컷) 캔버스 → 배경·장식·매장 이름을 디자인 → 사진 자리에 사각형을 놓고 그 사각형을 지운 뒤 투명 배경 PNG로 저장. ChatGPT 그림은 칸 위치가 들쭉날쭉하고 투명 칸을 잘 못 만들어서, 장식 그림만 ChatGPT로 만들고 칸 뚫기는 캔바에서 하는 것이 가장 깔끔합니다.

챗GPT로 캐릭터 프레임 만들기: 사진 자리를 흰 네모로 비운 그림을 그대로 [그림 올리기]에 넣으면, 앱이 흰 네모 칸을 찾아 사진 칸으로 바꿉니다 ("흰 네모 칸 4개를 사진 칸으로 바꿨어요"). 칸에 걸친 캐릭터·글자는 남고 사진 위에 얹힙니다. 마음에 안 들면 "원래 그림 그대로 쓰기". 요청 예: 애견 미용실 인생네컷 프레임을 만들어줘. 세로 1080×3240, 사진 넣을 자리 4칸은 완전한 흰색 네모로 비워 두고, 칸 사이와 둘레에 우리 가게 강아지 캐릭터(크림색 푸들)·꽃·별을 귀엽게 꾸며줘. 맨 아래에 영어로 'PET SALON'. 흰 네모 안에는 아무것도 그리지 마. 바탕은 흰색이 아닌 색으로 하세요 (흰 바탕이면 칸과 구분이 안 됩니다).

"칸 위치 가이드 저장"은 앱 기본 틀(배경 방식)에 맞춰 디자인할 때 씁니다. 덮기 프레임은 칸을 자동으로 찾으므로 없어도 됩니다.

보안 잠금 (마스터 코드)

설정 → 보안 탭에서 정합니다.

  • 마스터 코드 잠금: 4~8자리 숫자 코드를 정하면, 처음 보는 기기에서 앱을 열 때 코드를 묻습니다. 주소(URL)만 아는 사람을 막는 가림막입니다. 코드를 넣어 등록한 기기는 다시 묻지 않습니다.
  • 복구 코드: 마스터 코드와 함께 발급됩니다. 종이에 적어 안전한 곳에 두세요. [복구 코드 재발급]을 누르면 이 기기에서는 이전 코드를 바로 못 씁니다. 새 기기에서도 막으려면 이어서 나오는 GitHub 설정을 올려야 합니다.
  • 마스터 코드 변경 · 이 기기 등록 해제: 코드를 바꾸면 다른 모든 기기가 다시 등록해야 합니다. 그만둔 직원의 기기를 막을 때 씁니다.
  • 잠금 시도 한도 · 잠금 시간: 몇 번 틀리면(3·5·10회) 얼마 동안(30초·1분·5분) 막을지 정합니다. 막힌 뒤 또 틀리면 기다리는 시간이 매번 2배(최대 1시간)가 되고, 새로고침해도 초기화되지 않습니다.
  • 잠금 해제: [잠금 해제]는 먼저 이 기기에서만 끕니다 ("이 기기에서는 꺼짐"). GitHub의 master-config.js에 잠금이 남아 있으면 새 기기는 계속 묻습니다. 이때 나오는 [모든 기기 잠금 끄기]가 GitHub에서 바꿀 내용을 보여 줍니다.
  • 다른 기기에서도 잠금이 켜지게 하려면: [GitHub 배포 설정 보기]의 내용을 master-config.js에 올려야 합니다. 처음 설정할 때와 코드를 바꿀 때만 필요하고, IT에 익숙한 분의 도움이 필요할 수 있습니다.
강한 암호화가 아닙니다

이 잠금은 화면을 가리는 용도이고, 기기 안 데이터를 암호로 잠그지 않습니다. 휴대폰 화면 잠금(비밀번호·지문)을 함께 쓰세요. 잠금을 해제하면 주소를 아는 누구나 앱을 열 수 있습니다.

화면별 상세 설명

메뉴 · 검색

  • 휴대폰 더보기: 미용 기록(맨 위) · 매출 · 사진 카드 · 분석 · 서비스 메뉴 · 설정. 고객 화면 위쪽 [보호자 | 반려견] 탭으로 바꿔 보고, 마지막에 본 쪽을 기억합니다 (컴퓨터도 같음).
  • 검색: 휴대폰은 화면 오른쪽 위 돋보기, 컴퓨터는 왼쪽 메뉴의 찾기를 씁니다. 초성("ㅂㄷㅈ")과 띄어 쓴 여러 단어("초코 4444")도 됩니다. 검색에서 결과가 없으면 "+ 새 반려견 등록"이 나오고 검색어가 반려견 이름에 들어갑니다. 전화번호는 숫자만 비교합니다 ("0101111"처럼 하이픈 없이 쳐도 찾음). 결과를 누르면 전화·문자·예약·미용 기록, 미결제·최근 기록을 한 카드에서 봅니다. 넓은 컴퓨터 화면(1280px 이상)에서는 고객·미용 기록 목록을 누르면 오른쪽에 내용이 바로 열립니다.
  • 새 고객 등록: 반려견 이름을 비워 두면 "보호자만 등록할까요?"라고 묻고, 이미 등록된 연락처면 바로 안내합니다. 보호자 이름·견종·몸무게는 나중에 넣어도 됩니다.

홈

  • 급한 안전 안내(백업 긴급·동기화 끊김·홈 화면 추가)는 인사말 아래 한 줄, 가벼운 백업 안내는 맨 아래에 작게 나옵니다. 동기화가 정상이면 백업 경고는 며칠째 동기화가 안 될 때만 뜹니다.
  • 오늘 예약: 상태 대기·확정·미용중·완료·취소·노쇼. [미용 완료]로 저장하면 카드 상태·미결제·오늘 매출이 바로 바뀌고, 노쇼·취소 건에는 버튼이 없습니다.
  • 다음 영업일 리마인더: 내일이 휴무일이면 제목이 "다음 영업일(화)까지 예약 리마인더"로 바뀌고 항목마다 "월 11/10 10:00"처럼 날짜가 붙습니다. 사진·품종/체중, 발송 표시, 노쇼 경고가 함께 보입니다.
  • 연락할 손님: 세 탭 합계가 0이면 카드가 안 보입니다. 전화번호가 없는 손님만 "복사"(카톡 붙여넣기용) 버튼이 나옵니다. 카드 아래 "정상·올 때 됨·많이 늦음·오래 안 옴" 숫자를 누르면 고객 목록이 그 상태로 걸러집니다.
  • 미결제 현황: 5건까지 보이고, 더 있으면 "전체 N건 보기 →".
  • 오늘·이번 달 매출: 전월 대비 %와 목표 진행률.

예약

  • 월 달력에 반려견 이름 + 상태 색 바, 바쁜 날은 배경이 진합니다. 좌우로 밀면 달이 바뀌고, 토요일 파랑·일요일 빨강, 오늘은 파란 원 + "오늘" 버튼.
  • 반복 예약: 주 1회·2주·4주 등. 상태: 대기 → 확정 → 미용중 → 완료 (노쇼·취소면 [미용 완료]가 숨겨짐).
  • 완료된 예약 카드에는 상태 상자가 없고 결과 줄([기록 보기])과 [수정]만 있습니다. 기록 없이 완료한 예약은 결과 줄의 [기록 작성]으로 나중에 기록을 남깁니다. 잘못 완료 처리했다면 [수정] 맨 아래 [완료 취소]로 확정 상태로 되돌립니다(기록이 있는 완료 건은 기록을 삭제하면 예약이 되돌아갑니다).
  • 미용사가 2명 이상일 때만 타임테이블(8~22시)과 담당 미용사 칸이 보입니다. 1명이면 자동으로 채워집니다.
  • 반려견 이름으로 찾아 고객을 고르면 그 반려견이 자동 선택됩니다.

미용 기록

  • 서비스 칸 목록에는 미용 코스·단독 케어만 나오고(추가 옵션은 "추가 항목"에서), 오늘 몸무게 기준 가격이 함께 보입니다. 이미 넣은 추가 항목은 목록에서 빠집니다.
  • [서비스 제공]: 가격을 모르는 직접 입력 항목에는 나오지 않습니다. 켠 항목은 합계 아래 "서비스 제공: …" 한 줄과 목록 카드의 "서비스 제공" 표시로 보입니다. 리포트·사진 카드는 그대로입니다.
  • [이전 미용과 같음]: 서비스·추가 항목·가격·스타일·미용사·서비스 제공 상태를 채우고, 컨디션·협조도·결제 수단은 채우지 않습니다. 기록을 수정할 때는 보이지 않습니다.
  • 미용 협조도: 잘함·보통·까다로움 (다음 미용 시간 참고). 1인 매장이면 미용사가 자동 입력됩니다.
  • 다음 미용 추천일은 반려견 미용 주기로, 주기가 없으면 설정의 재방문 기준일(기본 30일)로 계산합니다.
  • 입력 중 바깥을 누르거나 끌어내리면 "작성 중인 내용이 있어요. 닫을까요?"라고 묻습니다 ([취소]·✕는 바로 닫힘).
  • 목록은 오늘·어제·이번 주·월별로 묶이고, 검색·필터 결과의 건수·합계·미결제 소계가 위에 보입니다. 삭제할 때 날짜·반려견·금액을 보여 주고 확인합니다.
  • 영수증: 기록 카드 [보호자에게 보내기] → [영수증]. 서비스 포함 항목(└ 발톱·귀청소·항문샘 등)도 나옵니다.
  • 리포트의 오늘 상태는 컨디션·협조·피부·귀·엉킴을 색 점으로 보여 줍니다. 고객 상세의 최근 기록에서도 리포트를 보낼 수 있습니다.
  • 기록 사진은 600px 축소본으로 동기화되어 다른 기기에서도 보입니다. 반려견 상세에서 전·후가 둘 다 있으면 타일 아래 "전 | 후"로 번갈아 봅니다.
  • 일일 정산표: 결제 수단별·미용사별 합계 + 시간순 내역.

고객 · 반려견

  • 고객 목록: 이름순·최근방문순·등록일순·방문횟수순. 검색하면 제목이 "검색 결과 N명 / 전체 N명"으로 바뀌고, 없으면 "검색 결과가 없어요". 방문 상태 필터는 홈과 같은 말(정상·올 때 됨·많이 늦음·오래 안 옴)을 씁니다.
  • 고객 상세: 방문 통계, 반려견, 정액권(반려견 아래 늘 있음), 미용 기록, 미결제, 메모, 전화·문자 버튼. 태그: VIP·신규·단골·주의.
  • 반려견 등록·수정 폼: 이름·보호자·견종·몸무게·성별·나이·생일만 보이고, 중성화·사진·성격·건강·알러지·스타일·권장 주기·상태(활동중·사망·양도)는 "+ 더 보기"에 있습니다. 사이즈 칸은 몸무게 구간표를 쓰는 동안 보이지 않습니다. 생일을 넣으면 나이를 생일로 계산합니다.
  • 반려견 상세: 다음 미용일(D-N)·최근 방문·최근 컨디션·협조도 5회 추이를 보여 주는 응대 카드, 알러지·건강 특이사항이 있으면 위에 빨간 경고, 전체 미용 이력(컨디션·협조도 색 점). 기록의 몸무게가 2개 이상이면 "최근 몸무게 5.2 → 5.4 → 5.6kg" 한 줄이 보입니다. 권장 주기를 안 넣으면 실제 평균 방문 주기로 다음 미용일을 계산합니다.
  • 반려견 목록: 왼쪽 색 띠와 상태 칩(많이 늦음·올 때 됨·정상·오래 안 옴). 정렬을 '상태별'로 하면 상태마다 묶여 나옵니다.

매출 · 분석

  • 매출 탭: 오늘(목표 진행률, 미결제 경고, 오늘 내역·결제 수단, 이번 주 일별 차트) / 이번 달(지난달 같은 날짜까지와 비교, 받은 돈 결제 수단별, 일별 차트와 주별 합계, 손익 — 고정비·변동비 입력 → 순이익). 지난달 데이터가 없으면 페이스·손익 카드 대신 한 줄 안내. 미용사별 매출은 미용사 2명 이상일 때만.
  • 분석 차트: 최근 6개월 월별 매출(기간 선택과 무관), 객단가 추이, 요일별 평균 매출, 시간대별 예약 건수, 미용사 성과(2명 이상일 때). 요일별·시간대별 그래프는 5건 미만이면 안 보입니다.
  • 분석 "오늘 점검할 것": 미결제 N건(누르면 명단 → 결제 수단 바로 변경), 많이 늦음 N마리, 올 때 됨 N마리(3마리 이상일 때), VIP 손님 N명 ○○일 이상 미방문(설정 › 매장 관리 › 재방문 알림 기준, 기본 30일). 누르면 카드 아래 5건 명단 + "전체 N건 보기 →", 이름을 누르면 상세로, 번호를 누르면 전화.
  • 분석 "이번 기간 분석": 재방문율, 매출 전 기간 대비, 평균 방문 주기, 견종 매출 비중, 가장 바쁜 요일, 인기 시간대, 객단가 변화, 신규 고객 추세, 노쇼율(취소 건은 빼고 계산), 협조도 까다로움 비율.

서비스 메뉴

  • 분류: 미용 코스 / 스타일 추가 / 추가 옵션 / 단독 케어 (설명은 [분류가 뭔가요?]). 가격은 [한 가격 / 몸무게별 / 무료] 버튼으로 고릅니다. 새 서비스는 미용 코스면 몸무게별, 나머지는 한 가격이 먼저 골라져 있고, 직접 바꾸면 그대로 둡니다. 가격을 비우면 "가격 미입력"으로 저장되어 기록할 때 직접 넣습니다.
  • 스타일 추가(테디컷·곰돌이컷 등 얼굴·부분 모양): 기록 폼의 서비스 아래 스타일 칩으로 나오고, 누르면 추가 항목에 값과 함께 붙습니다. 같은 스타일이라도 코스마다 값이 다르면 코스별 다른 값에 코스 이름 옆 값을 적습니다 (비우면 기본 가격). 미용 코스에 [스타일 추가 요금 안 받음]을 켜면 그 코스에서는 스타일을 골라도 0원(포함)입니다 — 예: 전체 가위컷.
  • 이 아이 가격: 반려견 상세의 "이 아이 가격"에 서비스별 값을 적어 두면(또는 기록에서 기본가를 고치고 [이 아이 가격으로 기억]을 켜면) 다음 기록부터 메뉴·몸무게 가격보다 먼저 들어갑니다. 견종·털 상태 때문에 늘 다르게 받는 아이에게 씁니다. 값 정하는 순서: 코스에 포함 → 이 아이 가격 → 코스별 다른 값 → 메뉴 값.
  • [저장하고 이어서 등록]: 분류·가격 방식은 두고 이름·가격만 비워 다음 서비스를 바로 적습니다. 새 서비스는 이 기기에서 마지막으로 쓴 가격 방식(단일가/구간)으로 열립니다.
  • 서비스명은 40자까지 (30자를 넘으면 글자 수 표시, 넘치면 자르지 않고 알려 줌). 이름을 바꾸면 과거 기록의 이름도 바꿀지 [기록 이름도 변경] / [이 서비스만 변경]으로 묻습니다 (매출·가격은 그대로).
  • "더 보기"(접힘): 큰 아이 추가 요금 · '~부터' 표시 · 포함 항목 · 설명. 켜 둔 것은 접혀 있어도 제목 옆에 짧게 보입니다. 포함 항목(발톱·귀청소·항문샘·발바닥·위생 미용·향수 + 직접 입력)은 영수증·사진 카드에 나옵니다.
  • 일괄 가격 조정: 전체/분류별 × 모든 구간/특정 구간, 금액/비율 (처음엔 "미용 코스"가 골라져 있음). 반올림은 설정 › 가격 구간의 단위를 따릅니다. [미리보기] → 목록으로 내려가고 버튼이 [N개 적용]으로 바뀜 → 한 번 더 누르면 적용. 무거운 구간이 앞 구간보다 싸지면 빨간 경고. 빈 칸은 올리지 않고, 특정 구간을 고르면 단일가 서비스는 그대로입니다.
  • [기본 서비스 등록]: 메뉴가 비어 있을 때만 보입니다. [전체 해제/전체 선택], "단일가로 등록"(작은 아이 가격 하나로). 목록 가격은 실제 저장될 가격과 똑같이 보입니다.
  • 카드를 누르면 수정, ⋯ 메뉴에서 복제·활성·삭제. 복제하면 "(복사본)"("(복사본 2)"…)이 붙고 "복사본 수정" 창이 열리며, 저장하지 않고 닫으면 남길지 묻습니다.
  • 목록 카드는 이름 · 가격 범위 · 큰 아이 추가 요금(붙을 때만) 최대 3줄입니다. 구간별 가격은 카드를 눌러 봅니다.
  • ⭐ 즐겨찾기는 위로, 분류 제목을 누르면 접기/펼치기, 비활성 서비스는 따로 접힘. 검색창에 결과 수가 보입니다.
  • 끝나지 않은 예약에 든 서비스는 삭제할 수 없습니다 — [비활성화]하면 메뉴에서만 숨겨지고 예약·기록은 남습니다. 지워도 예전 예약의 서비스 이름은 남습니다.

개발자가 관리하지 못하게 되면

펫살롱은 GitHub Pages라는 무료 호스팅에서 운영됩니다. 개발자가 관리하지 못하는 상황에 대비해 아래를 알아 두세요.

  1. 정기 백업: 주 1회 이상, 외장하드·클라우드·이메일 등 여러 곳에 보관. 백업 파일은 세무 상담·분쟁 증거로도 쓰이니 3~5년 보관을 권합니다. 고객 목록 같은 핵심 자료는 엑셀로도 따로 두면 좋습니다.
  2. 다른 호스팅: Vercel·Netlify 같은 무료 호스팅이나 자체 웹호스팅으로 옮길 수 있습니다 (IT 기술자 도움 필요).
  3. 다른 개발자에게 인수: 개발자 커뮤니티에 요청하거나 백업 파일을 주고 새 버전을 부탁합니다. 비슷한 다른 서비스를 찾는 방법도 있습니다.
  4. 다른 시스템으로 이전: 백업 파일 → 고객·반려견·예약·기록을 CSV/엑셀로 변환 → 새 고객 관리 프로그램으로 가져오기.

백업 없이 데이터를 잃었다면 IT 전문가에게 기기의 브라우저 저장소(IndexedDB) 복구를 문의할 수 있지만, 확실한 방법은 정기 백업뿐입니다.
